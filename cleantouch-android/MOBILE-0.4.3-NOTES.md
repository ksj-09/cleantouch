# Android 0.4.3

- 캡처 버퍼의 실제 픽셀만 행별 복사. 마지막 행의 패딩이 없는 기기에서도 처리.
- 캡처 콜백의 예외가 화면 공유 서비스 전체를 종료하지 않도록 복구 처리.
- 새 프레임 판별 시 기기의 프레임 시각을 기준으로 사용. 시각 정보가 없는 버퍼도 처리.
- 선택 중에는 위젯을 일시적으로 숨기고, 캡처 실패·시간 초과 시 위젯을 복원하며 스캔 유지.
- 캡처 해상도 상한 1280으로 조정하고 중간 패딩 비트맵을 제거해 메모리 사용 감소.
- 화면 회전 시 캡처 Surface 변경 실패를 처리하고 기존 Surface 복구.

갤럭시 A15 사용자가 보고한 증상에 대응한 변경입니다. 해당 실물 기기의 오류 로그는 확보하지 못했으므로 정확한 원인은 아직 확정하지 않았습니다.

검증: 버퍼·마스크·기존 기능 단위 검사 19개 통과. 에뮬레이터 화면을 1080×2340으로 변경해 선택 진입, 취소 후 위젯 복원 및 스캔 유지, 재선택 후 마킹과 Lens 화면 열기 통과. 검증 후 에뮬레이터 해상도를 복원했습니다.
