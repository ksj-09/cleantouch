- 사용자 보고: 이어서 분석 시 2/78에서 한도 초과 오류로 다시 중단.
- 실제 원인은 Groq의 분당 토큰 제한이며 해당 응답은 30초 뒤 재시도를 안내했습니다.

- 검색 서버 테스트 23개·빌드, Android 테스트 8개·린트·APK 빌드 통과.
- 대기 후 실제 이미지 요청이 HTTP 200으로 상품 후보 2개를 반환했습니다. 사용자의 전체 78장면 완료와 새 APK의 실기기 UI는 미검증입니다.
- APK versionCode 5, 0.3.1-debug. 기존 앱 위에 업데이트 설치해 저장된 녹화를 이어서 분석할 수 있습니다.

## 0.3.3 요청 수 제한과 Gemini 503 대기

- 새 녹화는 최소 5초 간격, 최대 24장면으로 분석합니다. 이전 `2/78` 녹화의 장면 시점과 완료 상태는 그대로 이어집니다.
- `PROVIDER_UNAVAILABLE` 503의 재시도 시각을 저장하며, 응답에 시간이 없으면 30초 대기합니다. versionCode 7 / 0.3.3-debug APK로 빌드합니다.

## 0.3.2 Gemini 전환

- 서버 기본 공급자는 Gemini이며 실제 비밀 키는 `.env`에만 저장하고 Android APK에 포함하지 않습니다.
- Gemini의 일시적 5xx는 서버에서 제한적으로 한 번 재시도합니다. 계속 실패하면 `503 / PROVIDER_UNAVAILABLE`와 안전한 안내 문구를 반환합니다.
- Android 응답 제한 시간을 90초로 늘리고, AI 서버 응답 지연을 네트워크/와이파이 연결 오류와 구분합니다. 실패 시 진행 결과와 녹화는 유지됩니다.
- API 키 인증과 모델 목록 조회는 성공했지만, 테스트 이미지의 실제 Gemini 분석은 `503 UNAVAILABLE`로 끝나 아직 성공 경로를 검증하지 못했습니다.
- `testDebugUnitTest`, `lintDebug`, `assembleDebug`가 통과했습니다. APK versionCode 6, 0.3.2-debug이며 같은 와이파이에서 `http://192.168.100.103:8099/app-debug.apk`로 내려받을 수 있습니다.
- 실기기 업데이트 설치, 검색 서버 재시작 후 `/health` 확인, 실제 상품 인식과 전체 78장면 완료는 별도 확인이 필요합니다.

## 출시 전 실기기 검증

2026-09-23 개발 검증: Android 16 에뮬레이터에서 53초 이상 녹화와 OFF 시 자동 분석 전환을 확인했습니다. 실제 공급자가 두 번째 장면 요청에서 무료 한도 초과를 반환해 전체 AI 성공 경로는 미검증입니다. 오류 이후 MP4 보존, 강제 종료·재실행 후 상태 복원 및 이어서 분석 버튼을 확인했습니다. 휴대폰용 LAN API 주소로 APK 빌드·업데이트 설치와 단위 테스트가 통과했습니다.

웹은 자동화 테스트로 11초 이상 ON 유지, 영상 위 버튼 없음, OFF 후 자동 예시 결과, 검색/필터/재시작 및 모바일 넘침 없음을 확인했습니다. 웹 결과는 실제 AI가 아닌 명시된 체험 데이터입니다. 서버는 다중 상품 파싱·상품별 링크/영역 보존·한도 오류 처리를 자동 테스트합니다.

- 여러 제조사 및 Android 10~16에서 시작/종료/권한 거절/알림 거절.
- 장시간 녹화, 화면 회전, 폴더블 화면 전환, 잠금, 저장 공간 부족.
- 서버 오프라인·한도 초과·프로세스 종료 뒤 복원 및 재분석.
- 실제 상품 인식 정확도와 누락률, 동영상 길이별 배터리/저장공간/분석 시간.
- HTTPS 배포, 서버 인증/요청 제한, 서명 키, 개인정보 처리방침.
- 실제 상품 카탈로그, 가격·재고 연동(현재는 쇼핑 검색 링크).
- 정식 백그라운드 서비스 심사 및 데이터 보존 정책 검토.

Android 시스템 화면 공유 표시와 동의창은 앱에서 숨기거나 바꾸지 않습니다.
