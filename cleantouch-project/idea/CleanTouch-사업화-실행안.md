# CleanTouch 사업화 실행안

작성 기준: 2026-10-13

## 제품 한 문장

영상을 보다가 마음에 든 상품을 터치하면 AI가 화면 흐름과 선택 영역을 확인하고, 실제 판매 후보와 여러 쇼핑몰 비교로 연결하는 화면 위 쇼핑 도우미입니다.

## 수익 구조

1. **제휴 구매 수익**: 네이버쇼핑·쿠팡·11번가·G마켓 등의 검색 결과로 연결하고, 각 판매처의 정식 제휴 승인을 받은 링크만 수익 링크로 전환합니다. 현재 앱에 추가한 링크는 일반 검색 링크이며 수익 링크라고 표시하지 않습니다. 쿠팡 파트너스는 방문자가 광고 링크를 거쳐 구매하면 구매금액의 일정 비율을 지급하는 구조를 공식 안내합니다: https://partners.coupang.com/
2. **CleanTouch Plus**: 무료 사용자는 일일 AI 분석 수를 제한하고, 유료 사용자는 긴 화면 함께 보기, 더 많은 전체 분석, 대화·상품 보관, 가격 알림을 제공합니다. 초기 권장 실험가는 월 4,900원과 7,900원 두 가지이며 실제 결제 전 가격 민감도 테스트로 하나만 남깁니다.
3. **B2B SDK/API**: 쇼츠·라이브커머스·OTT·크리에이터 플랫폼에 `영상 속 상품 찾기` 기능을 월 사용량 기반으로 제공합니다. 개인 사용자 광고보다 서버 비용을 예측하기 쉽고 상품 카탈로그를 직접 연동할 수 있습니다.
4. **브랜드 캠페인**: 검색 결과 상단 판매권을 파는 방식은 정확도를 훼손하므로 금지합니다. 광고 상품은 `광고` 표시와 일반 AI 결과 분리를 전제로만 운영합니다.

## 검색엔진 방향

- 1단계: AI가 선택 이미지에서 실제로 보이는 종류·색·형태만 짧은 검색어로 정제합니다.
- 2단계: 확인된 판매 출처 후보와 Google Lens 사진 비교를 먼저 보여줍니다.
- 3단계: 네이버쇼핑, 쿠팡, 11번가, G마켓, Google 쇼핑을 동일 검색어로 열어 사용자가 판매 사진을 비교합니다.
- 4단계: 제휴사 API 또는 정식 상품 피드를 확보하면 가격·재고·배송을 서버에서 정규화합니다. 제휴 데이터가 없는 가격과 재고는 AI가 만들지 않습니다.
- 쿠팡에 이미지를 직접 보내는 공개 이미지 검색 API를 전제로 하지 않습니다. 상품 이미지는 CleanTouch의 AI·Lens에서 해석하고 쿠팡에는 정제된 검색어로 연결합니다.

## AI 전처리 필터

앱에서 서버로 보내기 전에 다음 순서로 검사합니다.

1. 입력 형식과 크기, 역할 순서, 숨은 제어문자를 검사합니다.
2. 질문·화면 자막·검색 결과 안의 문장은 데이터로 취급하고 시스템 명령으로 실행하지 않습니다.
3. 사진이 없거나 흐릿해 상품 근거가 부족하면 브랜드·가격·재고를 추정하지 않습니다.
4. 앞뒤 장면으로 종류·색·점등 상태를 검증해 한 프레임의 반사와 전환 장면을 새 상품으로 만들지 않습니다.
5. 검색어는 화면에서 확인된 특징만 남기고 URL·명령문·보이지 않는 속성을 제거합니다.
6. AI 결과의 URL, 상품명 길이, 신뢰도와 판매 출처를 검사한 뒤 UI에 표시합니다.

## 출시 마케팅

- 첫 고객은 쇼츠·패션·장난감·인테리어 영상을 자주 보는 Android 사용자로 좁힙니다.
- 30초 데모 영상은 `영상 시청 → 떠 있는 버튼 → 상품 터치 → 비슷한 상품 비교` 한 흐름만 보여줍니다.
- 첫 지표는 다운로드 수보다 `스캔 시작 대비 상품 검색 완료율`, `첫 10분 내 성공 검색률`, `7일 재사용률`, `검색당 AI 비용`, `판매처 클릭률`입니다.
- 50명 비공개 테스트에서 성공 검색률 70%, 중단 없는 세션 95%, 사용자 1명당 주간 AI 비용 상한을 먼저 검증합니다.
- 개인정보를 다루므로 “영상을 모두 서버에 저장한다”는 오해가 생기지 않게 권한 화면과 소개 페이지에 프레임 처리 방식을 짧게 표시합니다.

## 투자 준비

- 지금 단계에는 프라이머·스파크랩 같은 초기 액셀러레이터가 제품 검증과 팀 구성을 다듬는 데 적합합니다. 프라이머는 공식적으로 초기 스타트업 배치와 시드 투자를 운영합니다: https://apply.primer.kr/ , 스파크랩은 공식 지원 페이지에서 액셀러레이터 접수를 안내합니다: https://sparklabs.co.kr/sp/apply.php
- 디캠프 배치는 출시 후 매출·재사용률이 생긴 스케일업 단계에 더 적합합니다. 2026년 배치 안내는 IT 서비스·솔루션, 제품 출시 후 성장 단계와 투자 연계를 명시합니다: https://dcamp.kr/program/batch
- 투자자료에는 기능 목록보다 세 숫자를 먼저 제시합니다: 7일 재사용률, 상품 검색 완료율, 검색 1회당 AI 원가 대비 제휴·구독 매출.
- 투자 신청 전 준비물: 1분 제품 영상, 10장 내외 IR, 개인정보 처리방침, 월별 서버비 표, 50명 테스트 결과, 제휴 링크 전환 데이터.

## 6주 실행 순서

1. 1주차: PC 회귀 테스트와 Android 에뮬레이터·Galaxy A15 실기기 안정화.
2. 2주차: 보안 점검, 분산 사용량 제한, 오류·비용 모니터링.
3. 3주차: 20명 비공개 테스트와 실패 화면 수집. 사용자 사진 원본은 수집하지 않고 실패 이유만 선택 입력.
4. 4주차: 검색 정확도·중복·전환 장면 보정, 판매처 클릭 이벤트를 개인정보 없이 집계.
5. 5주차: 50명 테스트, Plus 가격 두 안 비교, 쿠팡 파트너스 등 정식 제휴 신청.
6. 6주차: 지표가 기준을 넘으면 Play 비공개 테스트와 액셀러레이터 지원 자료 작성. 넘지 않으면 광고비 지출과 투자 지원을 미루고 정확도 개선에 집중.

## 출시 판단 기준

- 상품 선택 후 구매 비교까지 중앙값 15초 이내
- 테스트 장면에서 잘못된 상품 종류 10% 이하
- 앱 충돌 없는 세션 99% 이상
- 화면 공유가 사용자 허용 없이 시작되는 사례 0건
- 삭제한 대화·사진이 기기와 백업에 남는 사례 0건
- 사용자당 월 예상 AI 비용이 예상 매출보다 낮고, 무료 한도로 비용 상한을 유지
