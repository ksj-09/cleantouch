# 매출 아이디어 워크시트 초안 — 사용자 방향 반영판

## 1 / 3 — VeinID Exam

### 아이디어 이름

**VeinID Exam** — 신분증을 깜빡해도 응시 가능한 지정맥 본인 확인

### 한 줄 요약

자격시험 운영기관에 응시자가 미리 등록한 손가락 정맥으로 본인을 확인하는 서비스를 제공해, 신분증 미지참 민원과 대리시험 위험을 줄이고 기관당 첫해 8,000만 원을 번다.

### ① 문제

자격증 시험 당일 신분증을 깜빡하거나 분실한 응시자는 본인임을 증명하지 못해 시험을 못 볼 수 있다. 감독관은 예외 상황을 판단하기 어렵고, 시험기관은 신분 확인 민원과 대리시험 위험을 함께 관리해야 한다.

### ② 돈 내는 고객

돈은 국가·민간 자격시험을 운영하는 기관이 낸다. 쓰는 사람은 응시자와 시험 감독관이다. 시험기관은 본인 확인 시간을 줄이고, 신분증 미지참 민원과 대리응시 분쟁을 줄이기 위해 구매한다.

### ③ 우리 자산

- 손가락 정맥으로 본인을 확인하는 지정맥 인증 기술
- 금융 분야에서 본인 확인 시스템을 구축한 경험
- 공공기관이 요구하는 보안과 신뢰
- 여러 시험장에 같은 인증 정보를 배포하고 회수할 시스템 운영 능력

휴대전화 본인 인증만으로 지정맥을 등록하는 방식은 사용하지 않는다. 등록자가 다른 사람의 휴대전화를 들고 와 자기 정맥을 묶을 수 있기 때문이다. 최초 등록은 공인된 등록 장소에서 강한 신원 확인을 통과한 사람에게만 허용하고, 그 자리에서 확인한 신원과 지정맥을 묶어야 한다. 시험 당일에는 등록 때의 정맥과 같은지만 확인한다.

### ④ 수익 모델

- 시험기관용 시스템 구축비: 3,000만 원
- 시험장 단말기·운영 서비스: 장소·시험일당 50만 원 × 연 100회 = 5,000만 원
- 기관 한 곳의 첫해 매출: **8,000만 원**
- 이후에는 단말기 운영과 인증 건수에 따라 반복 매출을 받는다.

### ⑤ 첫 고객 1명

첫 제안 후보는 **한국산업인력공단의 국가자격시험 운영 부서**다. 실제 제안 전 신분증 미지참 응시자 수, 현재 예외 처리 절차, 생체인증을 공식 신분 확인 수단으로 인정할 수 있는지를 확인한다.

### ⑥ 3주 프로토

- 화면 1: 감독자용 신원 확인 완료 처리와 지정맥 사전 등록
- 화면 2: 시험장에서 지정맥을 읽고 사진·수험번호 표시
- 화면 3: 감독관용 인증 결과와 예외 처리 기록
- 데이터: 동의한 실증 인원 20명, 가상 수험 정보 20건
- 측정: 1명당 확인 시간, 타인 인증 차단 여부, 감독관의 사용 오류
- 성공 기준: 2초 안에 인증하고 등록하지 않은 사람은 통과시키지 않기

### 반드시 해결할 조건

지정맥이 서로 다르다는 사실만으로는 충분하지 않다. 쌍둥이 1의 계정에 쌍둥이 2의 정맥을 처음부터 등록하면 이후 인증은 정확하게 성공해 버린다. 이를 막으려면 최초 등록 때 정부가 확인한 다른 생체정보, 신뢰할 수 있는 전자신분증 또는 이에 준하는 대면 신원 확인으로 `사람과 법적 신원`을 먼저 묶어야 한다. 코리아퍼스텍이 이 신원 확인 수단에 접근할 수 없다면 이 아이디어는 보류한다.

### 스스로 점검

- [x] 돈 내는 고객과 사용자가 구분되어 있다.
- [x] 회사의 지정맥·금융·공공 신뢰 자산을 사용한다.
- [x] 실제 단말기 한 대가 있으면 3주 실증이 가능하다.

## 2 / 3 — CleanTouch Commerce

### 아이디어 이름

**CleanTouch Commerce** — 정보를 가리지 않는 터치형 쇼츠 쇼핑

### 한 줄 요약

자체 숏폼 플레이어를 운영하는 커머스 서비스에 영상 위 상품 카드 없이 제품 자체를 터치하면 정보와 구매 화면이 열리는 딤팩 SDK를 제공해, 고객사당 연 2,400만 원과 구매 수수료를 번다.

### ① 문제

쇼츠 영상에 상품명, 가격, 링크, 광고 문구가 계속 떠 있으면 옷의 핏, 화장 과정, 배경과 출연자의 움직임을 가린다. 정보를 숨기면 구매로 이어지지 않고, 정보를 계속 띄우면 영상 몰입도가 떨어진다.

### ② 돈 내는 고객

돈은 **자체 앱·웹의 숏폼 플레이어를 직접 수정할 수 있는 커머스 플랫폼 또는 영상 솔루션 사업자**가 낸다. 쓰는 사람은 그 서비스의 쇼츠 시청자다. 고객은 영상 완주율을 유지하면서 제품 클릭률과 구매 전환율을 높이기 위해 구매한다.

### ③ 우리 자산

- 영상 속 물건을 터치하면 정보와 구매로 이어지는 딤팩(DIMPEC) 기술
- 국내외 관련 특허 19건
- V-커머스 서비스 Boshow를 운영한 경험
- 제품 정보와 영상 속 등장 시점을 연결할 DB 구축 인력

영상 위에는 상품명과 가격을 계속 띄우지 않는다. 시청자가 궁금한 재킷, 신발, 화장품을 직접 터치할 때만 작은 정보창이 아래에서 열리고, 다시 누르면 구매 페이지로 이동한다.

### ④ 수익 모델

- 브랜드·플랫폼용 플레이어 연간 라이선스: 2,400만 원
- 해당 영상에서 발생한 구매액의 2% 수수료
- 고객사 한 곳에서 연간 구매액 1억 원이 발생하면: 2,400만 원 + 200만 원 = **2,600만 원**
- 첫해 10개 고객사 가정: **2억 6,000만 원**

### ⑤ 첫 고객 1명

첫 실증은 **Boshow 기술로 독립된 세로형 숏폼 플레이어를 만들어** 진행한다. 이 단계는 고객 확보가 아니라 기술과 사용성을 증명하기 위한 데모다. 첫 유료 고객은 KINX 미디버스처럼 쇼핑몰에 숏폼 플레이어를 공급하는 영상 커머스 사업자 또는 자체 숏폼 피드를 가진 중소 커머스 앱 한 곳으로 정한다. 같은 영상의 고정 상품 스티커 방식과 제품 터치 방식을 비교한다.

### ⑥ 3주 프로토

- 화면 1: 아무 상품 정보도 떠 있지 않은 세로형 쇼츠
- 화면 2: 영상 속 재킷을 터치했을 때만 열리는 상품명·색상·가격 카드
- 화면 3: 구매 페이지와 브랜드용 클릭·구매 통계
- 데이터: 쇼츠 5편, 영상 속 제품 20개
- 측정: 영상 가림 면적, 완주율, 상품 클릭률, 구매 버튼 도달률
- 성공 기준: 고정 상품 카드 대비 화면 가림을 없애고 상품 클릭률은 유지하거나 높이기

### 반드시 해결할 조건

유튜브와 틱톡 앱 안에는 외부 회사가 임의로 딤팩 기능을 넣을 수 없다. 따라서 처음부터 유튜브 쇼츠에 적용한다는 설명은 성립하지 않는다. 진입 순서는 `Boshow 기반 데모 → 자체 플레이어를 가진 소형 커머스 서비스와 SDK 실증 → 홈쇼핑·대형 커머스 앱 → 유튜브·틱톡 제휴`로 잡는다. 1단계 유료 고객을 찾지 못하면 기술은 작동해도 사업은 성립하지 않는다.

### 스스로 점검

- [x] 사용자가 직접 느끼는 불편이 분명하다.
- [x] 딤팩과 Boshow라는 회사 고유 자산을 사용한다.
- [x] 쇼츠 5편으로 3주 안에 A/B 비교가 가능하다.

## 3 / 3 — TapGuide

### 아이디어 이름

**TapGuide** — 웹과 실제 버튼 조명을 연결한 가전 사용설명서

### 한 줄 요약

전자기기의 QR을 찍어 열린 웹에서 버튼 이름을 선택하면 실제 기기의 해당 버튼 테두리가 빛나고 휴대전화에는 설명이 표시되는 안내 기능을 제조사에 제공한다.

### ① 문제

호텔, 펜션, 기숙사, 공유주방에서 처음 보는 전자레인지·세탁기·보일러를 사용하면 버튼 이름이 지워졌거나 뜻을 알기 어렵다. 설명서는 없거나 너무 길고, 외국인은 한글 버튼을 이해하기 어렵다. 사용자는 프런트나 관리실에 전화하거나 감으로 눌러 본다.

### ② 돈 내는 고객

돈은 전자레인지·세탁기·보일러·복합기처럼 버튼이 많은 전자기기 제조사와 이를 대량 운영하는 호텔·기숙사·렌탈회사가 낸다. 쓰는 사람은 제품 구매자, 투숙객, 학생, 외국인, 고령자다. 고객은 사용 문의, 잘못된 조작, 종이 설명서와 다국어 안내 비용을 줄이기 위해 구매한다.

### ③ 만드는 기술

이 아이디어는 회사 자산 카드에서 가져온 기술이 아니라 직접 만든 아이디어다.

- 제품 모델과 기기 ID를 불러오는 QR
- 앱 설치 없이 버튼 목록과 설명을 보여주는 모바일 웹
- 웹에서 선택한 버튼 정보를 기기로 보내는 Wi-Fi·블루투스 연결
- 각 실제 버튼의 테두리를 밝히는 LED와 제어 모듈
- 사용 목적에 따라 실제 버튼을 순서대로 밝히는 단계별 안내
- 한국어·영어 등 다국어 설명

예를 들어 웹에서 `30초`를 선택하면 실제 전자레인지의 30초 버튼 테두리 LED가 켜지고 휴대전화에는 `한 번 누를 때마다 30초가 추가됩니다`라는 설명이 표시된다. 조명은 위치만 안내하며 실제 조리 동작은 사용자가 기기의 버튼을 직접 눌러 실행한다.

### ④ 수익 모델

- 가전 모델 1종의 버튼 조명·웹 연동 개발비: 2,000만 원
- 제품 출고 1대당 소프트웨어 라이선스: 1,000원
- 한 모델이 5만 대 출고되면: 2,000만 원 + 5,000만 원 = **첫해 7,000만 원**
- 이후 설명 수정, 번역, 사용 통계 기능을 연간 유지비로 판매한다.

### ⑤ 첫 고객 1명

첫 제안 후보는 **SK매직의 전자레인지 상품기획·개발 부서**다. 버튼 테두리 LED와 통신 모듈을 넣은 실험용 조작 패널을 제시하고, 다국어 사용 안내 기능으로 제품 문의가 줄어드는지 공동 실증을 제안한다. 실제 제안 전 제조 모델과 외부 웹 연동 가능 여부를 확인한다.

### ⑥ 3주 프로토

- 화면 1: 전자레인지 QR 촬영 후 열리는 버튼 목록과 언어 선택
- 화면 2: `30초`, `해동`, `출력` 등을 누르면 표시되는 버튼별 설명
- 실제 장치: 선택된 버튼 테두리 LED가 1초 안에 켜지는 저전압 모형 조작 패널
- 단계 안내: `냉동밥 데우기`를 선택하면 실제 버튼이 순서대로 점등
- 데이터: 버튼 8~10개, 조리 목적 3개, 한국어·영어 설명
- 측정: 처음 사용하는 사람 10명의 완료 시간, 잘못 누른 횟수, 도움 요청 횟수
- 성공 기준: 사용자 90%가 도움 없이 조작하고 웹 선택 후 1초 안에 실제 버튼 점등

### 걱정되는 점과 대응

- 기존 전자레인지에는 버튼 조명과 통신 장치가 없음: 처음에는 제조사 신제품 기능으로 제안하고, 시제품은 안전한 저전압 모형 패널로 만든다.
- 인터넷이 끊기면 안내가 작동하지 않음: QR 설명을 기기 내부 또는 로컬 네트워크에 저장하고 블루투스 연결도 지원한다.
- 사용자가 조명만 보고 자동 실행됐다고 착각할 수 있음: 웹에 `위치 안내만 완료 — 실제 버튼을 누르세요`라고 명확히 표시한다.
- 잘못된 안내로 사고가 날 수 있음: 제조사의 공식 설명서만 사용하고 가열 금지 용기 등 필수 경고를 먼저 표시한다.
- 회사 자산 미사용: 워크시트의 회사 자산 필수 조건에서 감점되거나 제외될 수 있으므로 제출 전에 담당자에게 허용 여부를 확인한다.

### 스스로 점검

- [x] 돈 내는 고객과 사용자가 구체적이다.
- [ ] 회사 자산을 사용하지 않아 과제 조건 확인이 필요하다.
- [x] 저전압 버튼 모형과 웹으로 3주 안에 실제 시연이 가능하다.
