# IDEA

코리아퍼스텍의 기존 자산을 활용해 새로운 매출 아이디어를 구체화하는 프로젝트입니다.

## 과제 기준

모든 아이디어는 아래 네 가지를 만족하도록 작성합니다.

1. 돈을 내는 고객이 구체적이어야 한다.
2. 코리아퍼스텍의 자산을 하나 이상 사용해야 한다.
3. 3주 안에 작동 모습을 보여줄 수 있어야 한다.
4. 가격과 판매 수량을 이용해 매출을 계산할 수 있어야 한다.

## 파일

- `worksheet-draft.md`: 제출용 아이디어 워크시트 3개 초안
- `selection-score.md`: 지정맥 보안 검토와 딤팩의 단계별 시장 진입 계획
- `idea-notes.md`: 매일 한 줄씩 관찰과 아이디어를 기록하는 노트
- `parking-lot.md`: 나중에 검토할 세종IT타워 아이디어

## 지금 할 일

1. `worksheet-draft.md`에서 본인이 실제로 겪은 불편과 가장 가까운 아이디어를 고른다.

3. 예상 고객 1명에게 세 가지 질문을 하고 가격 가정을 수정한다.
4. 피드백 후 선정된 아이디어로 화면 3개짜리 프로토타입을 만든다.

## 고객 인터뷰 질문

1. 지금 이 일을 어떤 방식으로 처리하고 있나요?
2. 가장 불편하거나 시간이 오래 걸리는 부분은 무엇인가요?
3. 이 해결책에 연간 또는 건당 얼마까지 지불할 수 있나요?

> 아래 문서의 가격, 판매량, 부서명은 아이디어 검증 전의 가정입니다. 실제 제안 전에 담당자 인터뷰로 확인합니다.
