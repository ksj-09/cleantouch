# 예비 아이디어

워크시트 작성 전 단계의 후보만 보관합니다.

## 예비안 1 — HereNow

특정 장소에 가기 전에 현재 그곳에 있는 사람에게 대기시간, 재고, 좌석, 혼잡도 등을 질문하는 실시간 현장 정보 서비스입니다. 질문자는 소액을 내고, 위치가 확인된 현장 사용자는 답변이나 사진을 제공해 보상을 받습니다.

현재는 처음 제안한 개인 간 질문·답변 방식 그대로 보관합니다.

## 정식 아이디어로 이동 — TapGuide

전자기기에 붙은 QR로 웹을 열고, 웹에서 버튼 이름을 선택하면 실제 기기의 해당 버튼 테두리 LED가 켜지면서 휴대전화에는 설명이 표시되는 연결형 안내 서비스입니다. 정식 3번째 아이디어로 `worksheet-draft.md`에 옮겼습니다.

### 전자레인지 사용 예시

1. 전자레인지에 붙은 QR을 촬영한다.
2. 별도 앱 설치 없이 해당 모델의 안내 화면이 열린다.
3. 웹에 `30초`, `해동`, `출력` 같은 실제 버튼 이름이 표시된다.
4. 웹에서 `30초`를 누르면 실제 전자레인지의 30초 버튼 테두리 LED가 켜진다.
5. 휴대전화에는 `한 번 누를 때마다 30초가 추가됩니다`라는 설명이 표시된다.
6. `냉동밥 데우기` 같은 목적을 선택하면 실제로 눌러야 할 버튼이 순서대로 켜진다.
7. 사용자가 빛난 실제 버튼을 직접 눌러 제품을 작동시킨다.

휴대전화 카메라나 AR은 사용하지 않습니다. 제품에는 버튼별 LED와 Wi-Fi 또는 블루투스 제어 모듈이 필요합니다. 따라서 기존 제품에 QR만 붙이는 방식이 아니라 제조 단계에서 기능을 넣거나 별도의 버튼 조명 패널을 추가해야 합니다.

### 돈을 내는 고객 후보

- 호텔·펜션·기숙사·공유주방 운영사
- 가전제품 렌탈 회사
- 전자레인지·세탁기·보일러 제조사

고객은 사용 문의, 잘못된 조작, 외국인 안내 문제를 줄이기 위해 기기 또는 지점 단위로 사용료를 냅니다.

### 3주 시연 범위

- 전자레인지 모델 1개
- QR로 정확한 모델의 버튼 안내 웹 열기
- 웹에서 버튼을 선택하면 모형 패널의 실제 LED 점등
- 버튼별 설명과 한국어·영어 전환
- 조리 목적 하나의 단계별 버튼 안내

초기 시제품은 실제 전자레인지 고전압 회로를 건드리지 않습니다. 버튼 8~10개와 LED, 저전압 제어 보드로 모형 조작 패널을 만들고 웹의 선택 신호와 연결하면 3주 안에 안전하게 구현할 수 있습니다.
