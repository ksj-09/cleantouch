# Android 0.4.0 검증 기록

- 첫 화면 원형 시작 버튼, 화면 위 터치 선택, 작은 이동/축소 위젯.
- 화면 공유 중 약 3초 간격 장면 보관, 모두 분석 시 수집 일시정지, 지난 장면 직접 선택.
- 기기 내 객체 감지와 터치 윤곽 추출. 반복 후보는 색/형태로 묶고 등장 시각을 합침.
- 선택 이미지 자동 Lens 전달, 검색 결과 모바일 표시, 외부 판매처 링크 브라우저 연결.
- 사용자 API 키나 별도 서버 설정 없음. Lens로 보낸 사진만 Google 이미지 검색에 업로드.

검증 환경: Android 16 x86_64 에뮬레이터, 네이티브 x86 테스트 빌드. 시작 화면, 실제 모델 윤곽 추출, 로컬 전체 분석/반복 병합, 자동 Lens 업로드, 위젯에서 Lens Activity 열기를 검사했다. 테스트 사진은 프로젝트의 가방 이미지이며 실제 Google 유사 상품/쇼핑몰 결과 표시를 확인했다. 화면 증거는 `../artifacts/device-tests/lens-040-results.png`와 `marked-product-040.png`.

배포 파일은 별도로 ARM64/ARMv7, 비디버깅, R8 축소 빌드하여 서명을 검사한다. 에뮬레이터 테스트 APK를 배포하지 않는다. 실제 ARM 휴대폰, 유튜브/인스타그램, 회전/전원 관리 환경은 아직 검증하지 않았다.

제약: EfficientDet의 지원 클래스 밖 상품(의류/광선검 등)은 자동 목록에서 놓칠 수 있다. 터치 선택은 별도 경로로 지원한다. 마스크에 주변 물체가 포함되거나 일부가 누락될 수 있다. 반복 시점/조명 변화에 따른 완전한 동일 상품 판별과 Lens의 동일 상품/가격/재고는 보장하지 않는다. 장면 저장은 연속 동영상 녹화가 아니라 샘플링이다.

빌드: `testDebugUnitTest lintDebug assembleDebug`. 기기 테스트에는 `-PCLEANTOUCH_TESTING`, x86 에뮬레이터에는 추가로 `-PCLEANTOUCH_EMULATOR`. 실제 Google 업로드 검사는 instrumentation 인자 `lens=true`로 선택 실행한다.
