# Android 0.4.2

- OFF/ON 원형 버튼의 글씨·아이콘 대비 수정.
- 현재 장면을 먼저 고정한 뒤 상품을 터치하도록 변경해 영상 이동으로 인한 좌표 불일치 방지.
- 프레임 생성 시각을 확인해 위젯 메뉴가 남은 이전 캡처 제외.
- 넓힌 상품 후보 영역과 배경 지점을 사용하고 AI 마스크에 OpenCV GrabCut 경계 보정 적용.
- PC와 동일한 적응형 연결 영역 선택으로 옅은 마스크 보존, 떨어진 배경과 전체 화면 마스크 제외.
- 감지 영역 분할 중 예외가 나도 전체 장면으로 재시도. 모델 입력 이미지는 분할 완료까지 유지.
- 실패한 터치를 임의의 사각형 상품으로 저장하지 않고 같은 장면에서 재선택.
- 단위 검증: 낮은 확신도의 상품, 분리된 배경, 전체 화면 오선택, 작은 잡음 및 잘못된 값.
- Android 계측 검증: 시작 화면, 실제 모델의 가방 배경 제거, 위젯→장면 고정→터치→윤곽 확인→Lens 화면 열기.

모델이 모든 물건의 윤곽을 정확히 잡는 것을 보장하지 않습니다. 실물 휴대폰별 성능은 별도 확인이 필요합니다.
