CleanTouch

상품 연결 검증실

같은 모델·옵션과 실제 상품 상세 링크가 연결되는지 확인합니다.

로컬 개발용 · 1단계
실제 상품 자료가 아직 연결되지 않았습니다. 테스트 자료로 연결 경로를 검증할 수 있어요. AI 이미지 인식이나 실제 구매처 검색을 검증하는 화면은 아닙니다.

1. 상품 자료 연결

상품 ID·브랜드·모델·옵션·참조 사진·국가별 상세 링크를 등록합니다. 자료는 이 실행의 메모리에만 보관되며 외부 AI로 전송하지 않습니다.

자료를 선택해 주세요.

2. 식별자·옵션 확인

브랜드·모델번호 또는 GTIN을 기준으로 조회합니다. 같은 색·종류라는 이유만으로 동일 상품으로 표시하지 않습니다.

확인 결과

상품 자료를 불러온 뒤 확인해 주세요.

3. 등록 영상 상품 연결

판매자가 등록한 영상의 시각·선택 위치로 상품을 연결합니다. 기존 CleanTouch SDK의 시간·좌표 형식과 호환됩니다.



이 검증실은 공개 SaaS나 기업 인증 시스템이 아닙니다. 테스트 상품은 구매할 수 없으며, 판매자 자료도 사용 권한·품질·재고를 별도 검수해야 합니다. 계정·구독·이미지 검색 평가·모바일 통합은 이후 단계입니다.
