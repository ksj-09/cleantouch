## 남은 선행 조건과 다음 작업

1. 실제 상품 자료 확보: 상품·옵션 ID, 사용 가능한 참조 사진, 상세 URL, 국가/재고 갱신 및 사용 권한. 현재 사용자는 보유 여부를 모르는 상태이며, 확보한 것으로 가정하지 않았다.
2. 이미지 평가셋: 정답 SKU 포함/미포함, 가림·흐림·색·옵션·기기별 자료. 개발/평가 영상을 분리하고 오표시율·재현율·미확인 비율을 함께 측정한다.
3. 실제 사진 검색: 참조 이미지 특징 검색과 판매 사진 재검증을 연결. 현재 검증실은 입력 식별자/등록 태그 조회이며, 이미지 자동 식별기가 아니다.
4. 구매 검색 변경: 2026-10-16 Windows 0.1.62에 원본 맥락 연결·판매 후보/일반 검색 분리·식별자 검증을 반영하고 서버 배포를 완료했다. 실제 상품 분석 요청은 성공했지만 외부 판매처 검색은 사용량 제한으로 후보 0개였다. 실제 동일 상품 구매처 검색 성공은 아직 검증되지 않았다. 상세: `cleantouch-desktop/QUALITY-0.1.62.md`.
   같은 날 0.1.63에서 실제 Gemini 비교 중 발견한 후보 번호/링크 뒤바뀜을 고유 식별자로 수정하고, 실제 판매 사진의 색상·종류 대조를 검증했다. 정상 상세 페이지가 1 MB를 넘어서 탈락하던 문제와 Live 도구의 사진 base64 텍스트 재전송도 수정했다. 검색 공급자 분리·실패 대기·동시 요청 공유를 구현해 배포했다. **운영 자동 판매처 검색은 계정 결제/접근 제한 때문에 아직 차단되어 있다.** 실제 판매 사진 검사는 평가자가 URL을 제공한 통제 검사이며 자동 검색 성과가 아니다. 상세: `cleantouch-desktop/QUALITY-0.1.63.md`.
5. 사용량·원가 계측과 운영 통제: 사용자 인증·조직별 권한·분산 쿼터·청구 원장·실패 정책. 현재 로컬 세션 보호를 상용 인증으로 간주하지 않는다.
   2026-10-16 추가: Windows 0.1.64 기기 서명과 운영 PostgreSQL 공통 요청 원장·재전송 차단을 반영했다. 운영에서 정상 서명 200, 재전송 409, 변조 401 확인. 회원 로그인/조직 권한이나 실제 금액 청구 상한이 완성된 것은 아니다. 상품 ID/종류 인식의 독립 평가 도구도 추가했으나 평가 자료 부족으로 품질 통과를 보류한다. 상세: `cleantouch-desktop/QUALITY-0.1.64.md`.
6. 제한된 B2B 실증과 Android 실기기 검증. 이후 구독, MCP, iOS, 해외 국가를 통과 조건에 따라 확장한다.
