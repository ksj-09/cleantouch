# 공통 이용량 보호·정확도 평가 — 2026-10-16 / Windows 0.1.64

## 반영

- 서버 인스턴스·배포에 공통인 PostgreSQL 이용량 원장. 서비스 전체·기기·네트워크·분당 한도를 한 트랜잭션에서 검사하고 차감한다. 일일 공통 행 잠금으로 동시에 들어온 요청의 초과 차감을 막는다.
- Windows 기기별 Ed25519 요청 서명. 개인키는 메인 프로세스의 Windows 보안 저장소로 보호하며 외부 AI 키를 사용자 앱에 배포하지 않는다. 요청 내용·시각·난수를 검증하고 데이터베이스에서 재전송을 거절한다.
- 기존 모바일/PC는 네트워크별 제한된 legacy 경로를 둔다. 임의의 서명 오류는 legacy로 우회하지 않는다. 저장소 오류는 AI 공급자 호출 전에 멈춘다.
- 상품 사진 대화의 원본 장면이 최초 식별 뒤 빠지던 부분을 보완했다. 후속 사진 질문과 대화 저장/복원에서도 원본 장면 한 장과 선택 사진을 함께 전달한다. 새 사진 업로드와 새 대화에는 이전 장면을 물려주지 않는다. 사진·장면 합계가 요청 크기를 넘지 않도록 선택 사진의 전송 크기를 제한한다.
- 상품 ID 평가와 상품명/색상 인식 평가를 분리했다. 오표시·미검출·분석 오류·후보 없음, 상품군과 조건별 지표를 기록한다. 동일 원본 그룹의 개발/평가 중복과 예측 중복을 거절한다. 자료 부족 상태에서 품질 통과로 표시하지 않는다.
- 서버 이미지 처리 라이브러리 Sharp의 보안 수정 버전을 반영했다. 운영 의존성 감사 결과 취약점 0개.

## 확인

- API 단위/통합 테스트 115개, PC 단위 테스트 144개 통과. 로컬 Express JSON 경로의 정확한 본문 서명 검사·플랫폼 IP 헤더 위조 거절, 기존 multipart 경로의 긴급 정지도 포함한다.
- 전용 로컬 PostgreSQL에 동시 30개 요청: 한도가 허용한 10개만 승인되고 20단위 차감. 같은 요청 재전송과 한도 거절 시 추가 차감 없음.
- Netlify 운영 DB 정식 마이그레이션 적용. 실행 자격증명에 스키마 생성 권한을 추가하지 않았다. 관리 API로 마이그레이션을 적용하고 실행 함수 권한을 검증했다.
- 운영 배포 `6ad17c640b7050573a589578`에서 Windows 서명 모듈로 만든 정상 요청 200, 같은 요청 재전송 409, 본문 변조/잘못된 서명 401 확인. 공통 이용량 보호 required 상태. 운영 AI 사진 분석과 기존 요청 호환 확인.
- Electron 검사: 원본 장면 저장·복원·후속 질문 포함, 새 사진의 이전 장면 분리, 대화 복원·취소·재시도·실패 처리 통과.
- Windows 0.1.64 설치형·포터블을 Downloads에 생성했다. ASAR의 main/service-client/request-signer/place-chat/shopping-cards/chat-store 파일이 현재 소스와 일치한다. 파일 크기와 SHA-256은 `usage-0.1.64-package.json`에 기록했다. 현재 실행 중인 이전 앱을 강제 종료하거나 대화를 지우지 않았다.
- 실측 오류: 잘린 광선검 사진 단독 요청에서 ‘빨간색 칫솔’ 응답이 나왔다. 실패 사례로 남겼다. 원본 장면을 함께 보낸 상품 식별과 후속 사진 대화에서는 광선검으로 응답했다. 소수 사례이며 일반 정확도 향상 수치를 입증하지 않는다.

## 아직 남은 것

**상용 품질 인증을 끝낸 버전이 아니다.** 독립 상품/영상 평가 자료가 부족해 holdout 판정은 `insufficient_data`다. 종류·색상 인식, 동일 SKU 식별, 자동 판매처 검색을 같은 성공률로 섞지 않는다.

기기 서명은 회원 로그인/사람의 신원/앱 무결성 인증과 다르다. 기기를 다시 생성할 수 있어 네트워크·전체 한도를 함께 둔다. B2B 조직 권한, 구독 계정과 기기 복구는 별도 작업이다.

이용량 단위는 실제 청구 금액 상한이 아니다. 특히 Live 토큰 발급 수만으로 음성 세션의 실제 지출을 강제 제한하지 못한다. 결제 활성화 전에 공급자 한도·청구 계측·필요한 서버 중계를 확인해야 한다. 외부 판매처 검색은 기존 Google 계정의 접근/결제 제한으로 여전히 후보 0개였다. Android 서명 기능과 새 APK는 이번 작업에 포함하지 않았다.

관련 문서: `../cleantouch-search-api/USAGE-PROTECTION.md`, `QUALITY-EVALUATION.md`. 검증 결과는 `../artifacts/verification/usage-0.1.64-*.json`, `usage-0.1.64-*.txt`, `quality-*.json`에 있다. 보고서에는 비밀값·이미지 본문·실제 대화 내용을 넣지 않았다. 단, 공개 시험 사진에 대한 AI 답변은 개발용 실증 보고서에 들어 있다.
