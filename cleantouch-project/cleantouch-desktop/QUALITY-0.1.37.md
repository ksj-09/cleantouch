# CleanTouch PC 0.1.37

사용자가 공유 중인 상품의 구매를 요청하면 확인된 종류·색·형태로 유사 상품 검색 카드를 제공합니다. 정확한 브랜드를 모른다는 이유로 구매 안내를 거절하지 않습니다. 카드에는 질문 당시의 상품 부분 사진, 쇼핑 검색, 해당 사진을 직접 전달하는 Lens 비교 버튼이 있습니다. 질문 뒤 영상이 바뀌어도 다른 장면으로 검색 사진이 바뀌지 않습니다.

대화창의 X는 AI 화면 공유를 종료하고 창을 닫습니다. 대화는 유지합니다. 상단 목록 버튼에서 이전 대화를 선택하거나 새 대화를 시작할 수 있습니다. 큰 화면에서는 옆 사이드바, 위젯에서는 대화 목록 패널을 사용합니다. 기록은 이 PC의 앱 데이터에 저장되며 앱 재시작 후에도 불러올 수 있습니다. 대화의 텍스트·선택 사진·검색 버튼을 복원하고, AI 재연결 시 이전 문맥과 마지막 상품 참고 사진을 전달합니다. 지속적으로 공유하는 모든 프레임을 기록으로 보관하지 않습니다.

최근 40개 대화를 최대 24MB까지 보관합니다. 개별 대화는 최근 120개 메시지, AI 재연결 문맥은 최근 40개 발화를 유지합니다. 대화별 삭제와 삭제 확인을 제공합니다. 손상된 기존 저장 파일은 덮어쓰지 않으며, 저장은 임시 파일과 원자적 교체로 처리합니다. 늦게 도착한 AI 응답·검색 결과가 다른 대화에 들어가지 않도록 요청 취소와 세대 검사를 유지합니다.

## 검증

- PC 단위 테스트 75개 통과: 기존 캡처·마스킹·분석 중단·업데이트 검사, 저장/재시작/삭제/손상 파일, 과거 대화 전달, 구매 도구 응답 및 오래된 도구 결과 차단 포함.
- API 테스트 61개 통과: 검색 출처에 실제 존재하는 URL만 유지하며 잘못된 출처 인덱스·허위 URL·중복을 제외합니다. 검색 결과가 없으면 후보를 만들어내지 않습니다.
- Electron 통합 검사에서 닫기 후 내용 유지, 이전 대화 선택, 제공된 상품 사진 및 검색 버튼 복원, 사진 질문과 Lens 전달, 대화 삭제를 검증합니다.
- 실제 열려 있는 YouTube 영상과 Gemini Live 연결에서 구매 의도 → 상품 사진·검색 카드, X로 공유 종료 → 재열기, 저장된 대화 복원, 위젯 목록과 큰 화면 사이드바를 확인했습니다. 검증 화면과 JSON은 artifacts/verification/release-0.1.37-*에 있습니다.
- 최종 패키지를 새 프로세스로 다시 실행해 저장된 대화, 구매 카드 3개, AI 문맥 복원 및 공유 자동 시작 안 함을 확인했습니다. 설치 종료 코드 0, 설치 버전 0.1.37, 설치된 핵심 파일 10개와 최종 패키지·소스가 일치함을 확인했습니다. 두 Windows exe에 운영자 키가 포함되지 않음을 검사했습니다.

## 범위와 제한

- 운영 계정에서 실제 판매 링크를 찾는 Google 검색 기능은 사용 한도 응답(429)을 받았습니다. 현재 실제 검사에서 판매 후보 링크는 0개였으며, 쇼핑 검색과 Lens 이미지 비교 버튼으로 이어집니다. 검증되지 않은 판매처·가격·재고·동일 상품·유사율 수치는 표시하지 않습니다. 운영 계정에서 검색이 가능해지면 실제 검색 출처를 외형 근거로 비교한 판매 후보를 최대 3개 표시하는 경로를 구현했습니다. 판매 사진 자체를 모두 내려받아 계산한 수치형 이미지 유사도는 아닙니다.
- 모델의 상품 경계·명칭은 추정입니다. 저화질·가려진 상품에서는 잘못 추정할 수 있으므로 직접 상품 영역을 선택하는 기능과 Lens 비교를 함께 제공합니다.
- 기존 서버에 구매 도구와 구버전 호환 연결을 배포했습니다. 그 뒤 중복 배포는 Netlify의 Forbidden 응답으로 실패했으나, 성공한 배포의 기능으로 실제 Live 구매 카드 검사가 통과했습니다.
- 이번 대화 목록과 Live 구매 카드 변경은 PC에 적용했습니다. Android APK는 0.4.8이며 동일 UI를 새로 빌드한 버전으로 안내하지 않습니다.
- 코드 서명 및 GitHub 새 릴리스 공개는 진행하지 않았습니다. 설치 파일과 휴대용 실행 파일을 로컬로 제공합니다.
