# 상품 식별·판매처 검증 — Windows 0.1.62 / 2026-10-16

## 반영 내용

- 저장된 상품의 AI 분석은 작은 상품 사진뿐 아니라 그 사진을 가져온 원본 장면과 선택 위치를 함께 전달한다. 선명한 사진으로 교체할 때 원본 장면도 같이 교체한다. 같은 영상의 가까운 장면만 보조 근거로 사용한다.
- 색상·종류만 같은 경우 서로 다른 외형을 강제로 합치던 경로를 제거했다. 기존 임베딩·위치·영상·동시 등장 검사와 충분한 시각 근거가 있는 중복 통합은 유지했다.
- 판매처 검색은 실제 상품 상세 페이지와 판매 사진을 확보한 뒤 기준 사진과 비교한다. 외형이 가까운 후보에 판매 사진, 판매 페이지, 비교 특징과 다른 점을 표시한다.
- 사진에 보이는 브랜드·모델 식별자가 판매 페이지 메타데이터와 일치하고 옵션 비교도 통과해야 ‘모델 식별자 일치’ 후보가 된다. 모델번호 접두어 일치나 서로 다른 한글 브랜드를 일치로 처리하지 않는다. 사진 외형만으로 동일 모델을 보장하지 않는다.
- 서버리스 요청이 다른 인스턴스로 분리돼 식별 캐시가 없더라도 실제 판매 메타데이터에 모델 단서가 있으면 식별을 다시 수행한다. 판매처 검색부터 실패한 경우에는 추가 식별 호출을 하지 않는다.
- 일반 쇼핑몰 키워드 검색은 접힌 별도 영역에서 ‘동일 상품 미확인’으로 안내한다. 검색 목록 URL·판매 사진 없는 응답·검증되지 않은 후보는 판매 상품 카드로 노출하지 않는다.
- 검색 중 상태를 기존 안내 문구에 반영하고 결과/실패 상태로 교체한다. 저장 도중 중단된 판매처 검색이 대화 재열기 시 영구 로딩으로 남지 않게 했다. 대화 기록에 사진 비교 근거와 차이점도 보존한다.

## 남은 핵심 제약

**운영 서버의 외부 판매처 검색은 현재 사용량 제한으로 실패했다. 실제 판매 후보는 0개였다.** 따라서 이번 검증은 실제 동일 상품의 구매처 검색 성공, 일반 상품 전체의 정확도 향상 수치 또는 상용 준비 완료를 입증하지 않는다. 운영 응답은 `comparisonStage: search_unavailable`과 현재 구매처가 확인되지 않았다는 안내를 반환한다. 제한을 숨기거나 허위 상품/링크로 대체하지 않는다.

판매 사진 비교와 식별자 분기 성공은 통제된 테스트 자료로 검증했다. 실제 판매처 데이터 연동과 독립 평가셋이 필요하다. AI가 읽은 식별자와 판매자 메타데이터도 오류가 있을 수 있으므로 구매 전 옵션 확인이 필요하다. 가격·재고·결제는 검증하지 않았다. Android는 이번 빌드에 포함하지 않았다.
