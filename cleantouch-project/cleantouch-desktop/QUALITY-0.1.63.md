# 실제 판매 사진·링크 연결 엔진 — 2026-10-16 / Windows 0.1.63

## 확인한 핵심 결함과 변경

1. **판매 사진과 링크가 바뀔 수 있는 후보 번호 오류.** 실제 Gemini 사진 비교에서 0 기반 번호를 1 기반으로 반환하는 사례가 발생했다. 모델이 검은 이어폰을 일치 판정했는데 흰색 판매 페이지로 연결될 수 있었다. URL 해시로 만든 고유 `sourceId`를 사진과 함께 전달하고 응답 스키마의 enum으로 제한한다. 반환된 식별자가 정확히 존재할 때만 해당 사진·링크를 연결한다. 번호·알 수 없는 식별자는 거절한다. 같은 최종 판매 URL은 한 번만 비교한다.
2. **판매 페이지 용량 제한.** 실제 공식 판매 페이지가 약 1.88 MB여서 기존 1 MB 제한으로 탈락했다. HTML 상한을 4 MB로 조정했다. HTTPS·DNS 주소 고정·비공개 IP 차단·리디렉션 재검증·이미지 크기와 픽셀·시간 제한은 유지한다.
3. **상품 사진과 메타데이터의 혼선.** 구조화된 상품 사진이 있으면 일반 OG 미리보기보다 우선한다. 여러 상품 메타데이터가 섞인 페이지는 거절한다. ProductGroup과 여러 옵션을 단일 식별자 근거로 사용하지 않는다. 검색어 쿼리 URL을 판매 상세 링크로 취급하지 않는다.
4. **색·종류만 비슷한 결과.** 실제 사진 비교에서 상품 종류와 구별 가능한 구조가 모두 맞아야 후보로 유지한다. 명시적으로 다른 옵션은 제외한다. 외형 근거만 있으면 유사 후보이며, 동일 모델을 확정하지 않는다.
5. **검색/분석 능력 혼합.** Cloud Vision 웹 이미지 페이지 검색과 Gemini 검색 연결을 독립 공급자로 분리했다. 검색 모델과 사진 비교 모델을 분리했다. 사용 가능한 경로를 순서대로 시도하며 billing/configuration/일시 제한을 구분한다. 계정·결제·모델 접근 권한을 자동 변경하지 않는다.
6. **중복 비용과 취소.** 서로 다른 사진에도 공급자 실패 대기를 공유한다. 같은 사진·검색어 동시 요청은 작업을 공유한다. 한 호출자의 취소로 다른 호출을 취소하지 않으며, 모두 취소하면 공급자 요청도 취소한다. 결과 캐시는 제한된 함수 메모리 안에만 있다.
7. **Live 응답의 사진 문자열 낭비.** 판매 사진은 UI에 유지하면서 AI 도구 결과에는 짧은 이름·상세 링크·비교 근거만 전달한다. base64 사진을 텍스트로 다시 전송하지 않는다. Live 검색 실패도 카드 상태에 반영한다.

## 검증 근거

- 서버 테스트 106개, PC 단위 테스트 141개 통과.
- Electron 대화와 상품 선택/장면 연결 통합 검사 통과. 네트워크 실패를 의도적으로 넣어 복원·재시도·늦은 응답 차단을 확인했다.
- 실제 공식 판매 페이지 두 곳에서 사진을 읽었다. 평가자가 후보 URL을 제공하고 검은 이어폰 사진의 일부를 기준으로 실제 Gemini 비교를 수행해 검은 옵션 링크 유지·흰색 옵션 제외를 확인했다. 광선검 사진에 같은 이어폰 후보들을 넣었을 때 후보 0개를 확인했다. 보이지 않는 모델번호를 만들거나 동일 모델로 승격하지 않았다.
- 위 평가는 **통제된 판매 사진 비교 검사**다. 후보 URL을 평가자가 제공했으므로, 자동 검색 성공이나 일반 상품 전체의 정확도 수치를 뜻하지 않는다. 최초 검사에서 번호 오류로 실패했고, 식별자 변경 후 통과했다.

- Windows 설치형·포터블 0.1.63 빌드와 다운로드 폴더 복사를 완료했다. ASAR의 주요 런타임 5개 파일이 소스와 바이트 단위로 일치한다. 상세 경로·크기·SHA-256: `purchase-0.1.63-package.json`.

## 운영 검색은 아직 외부 설정에 막혀 있음

직접 확인한 결과 기존 Cloud Vision 키는 **403 BILLING_DISABLED**, Gemini 3.1 Flash-Lite의 Google 검색 연결은 **429 RESOURCE_EXHAUSTED**였다. 공식 문서상 이 모델의 일반 무료 추론과 검색 연결 지원은 별개다. 무료 검색이 문서에 있는 Gemini 2.5 Flash/Flash-Lite도 이 계정에서는 **404 신규 사용 불가**였다. 모델 목록 노출만으로 사용 가능하다고 판단하지 않는다.

이 코드 변경으로 운영 계정의 결제/접근 제한이 해제되지는 않는다. 자동 판매처 검색은 현재 정상화되지 않았으며, 결제 활성화 또는 이용 가능한 정식 공급자 설정과 실제 요청 성공 확인이 필요하다. 사용자에게 키 발급을 요구하지 않는다. 운영자 프로젝트만 설정한다. 이전 결제 등록 보류 의사를 임의로 변경하지 않았다.

검색 경로의 쿼터와 캐시는 인스턴스 단위다. 기업용 인증·분산 사용량/원가 통제·실판매 정답 평가셋·Android 실기기 검증까지 끝났다는 의미는 아니다. 운영 결제를 연결하기 전 비용 통제 정책도 확인해야 한다.
