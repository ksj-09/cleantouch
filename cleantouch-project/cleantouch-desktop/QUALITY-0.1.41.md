# CleanTouch PC 0.1.41

사용자가 지적한 문제는 앞에서 한 말을 잊거나 엉뚱한 답변을 하는 것이었습니다. 사진 요청의 최근 12개 발화와 Live 재연결의 최근 40개 발화에만 의존하던 경로를 보강했습니다. 대화별 참고 기록을 별도로 보관하고 새 질문 직전에 그 기록을 다시 전달합니다. 화면 프레임이 오래 쌓이거나 연결이 갱신돼도 참고 기록을 재전달합니다.

`conversation-context.js`는 실제 사용자/AI 텍스트만 기록합니다. 실패한 답변·내부 역할·사진 바이트는 제외합니다. 최신 정정이 마지막에 남도록 반복 발화의 순서를 유지하며, 복원한 메시지의 중복 재생은 합칩니다. 최초 32개와 최근 128개 발화를 최대 160개로 보관합니다. 전달 시 최근 내용·질문에 관련된 내용·이름/예산/선호 등 조건을 우선해 최대 16,000자 메모를 구성합니다. 따라서 무제한 과거 기억이나 모든 답변의 정확성을 보장하는 기능은 아닙니다.

메모에는 과거 기록이라는 표시를 붙이고 현재 화면과 구분하며, 사용자 정정을 우선하고 AI의 추정을 확정 사실로 쓰지 않도록 안내합니다. 일반 질문은 기존 Live 연결에서 텍스트 메모를 전달하므로 추가 연결을 만들지 않습니다. 사진 요청도 서버의 13개 메시지/메시지당 3,000자 제한을 유지하면서 메모를 포함합니다. 별도 요약 모델 호출은 추가하지 않았습니다.

AI 채팅 안의 사진 상품 분석이나 화면 상품 선택은 현재 대화 ID·이전 메시지·조건을 유지합니다. 명시적인 새 대화에서는 메모를 비우고, 다른 대화 선택 시 해당 대화의 메모만 복원합니다. 기존 대화 저장·생성 제목·공유 허용 기능은 유지합니다.

## 검증

- 단위 테스트 93개 통과. 긴 대화의 초기 조건 보존, 최신 정정 순서, 복원 중복 방지, 실패/이미지 제외, 저장 화면에서 오래된 메시지가 잘려도 메모 보존, Live 갱신 후 메모 재전달을 포함합니다.
- 소스 및 최종 asar Electron 통합 검사 통과. 채팅 안 상품 분석의 ID/이전 메시지 유지, 메모 저장/복원, 새 대화 격리, 사진 요청의 이름·정정 예산 전달과 메시지 제한을 검사했습니다. 기존 공유 동의·Lens·대화 목록/제목 검사도 유지합니다.
- 실제 Gemini/앱의 격리된 QA 프로필에서 180개 중간 발화 뒤 질문했습니다. 최근 AI 문맥과 표시 메시지에는 초기 이름이 없는 상태였지만, “민지 / 초록색 가방 / 정정 예산 8만원”을 정확히 답했습니다. 대화를 닫고 다시 열어 새 AI 연결에서도 동일하게 답했습니다. 메모 2회 전달, 사진/캡처/공유 없음 확인. 자료는 `artifacts/verification/release-0.1.41-memory-real.json`과 PNG입니다. QA는 작성한 예시를 사용하며 실제 사용자 대화를 시험 데이터로 보내지 않았습니다.
- 모델·공개 서버·Android APK는 이번 작업에서 변경하지 않았습니다. 모델을 바꿔 지능이 전반적으로 개선됐다는 의미가 아니라, 앱이 기억을 누락하던 경로를 수정한 것입니다. 원래 이미 저장에서 제외된 옛 메시지를 되살릴 수는 없습니다.
- Windows 설치 종료 코드 0, 버전 0.1.41 및 핵심 17개 파일의 설치본/asar/소스 일치를 확인했습니다. 기존 사용자 대화 4개의 메시지·문맥·사진 해시와 시각을 교체 전후 비교해 보존을 확인했습니다. 생성된 제목 4개도 유지했습니다. 패키지 329개 파일/기존 APK 545개 파일 및 두 실행 파일에서 운영자 키 미포함을 확인했습니다. Setup/Portable은 Downloads와 artifacts/downloads에 저장하고 해시/업데이트 파일을 준비했습니다. 공개 릴리스는 게시하지 않았습니다.
