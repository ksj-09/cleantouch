# 0.1.53 — 선택 상품과 구매 후보 연결

- 마킹된 상품 내부의 색·불투명도를 보존하고 배경만 제거합니다. 클릭이 선택 마스크 밖이면 인접 물체로 대체하지 않습니다.
- 직접 선택 분석은 상품 윤곽 사진을 기준으로 삼고, 같은 영상의 근접 장면을 선택적으로 참고합니다. 업로드 사진에는 스캔 기록을 섞지 않습니다.
- 상품 확인 후 판매 사진 비교를 자동으로 진행합니다. 실제 Product/ProductGroup 메타데이터의 상품 사진을 확보하고 AI가 기준 사진과 비교한 높은 근접도의 후보만 표시합니다.
- 구매 카드에 판매 사진과 비교 근거를 표시합니다. 확보하지 못한 사진이나 약한 유사도는 검증된 후보로 표시하지 않습니다.
- 동일 사진·검색어 결과를 짧게 재사용합니다. 성공 후보는 최대 5분, 빈 결과는 최대 1분이며 항목 수를 제한합니다.
- 서버 외부 요청은 HTTPS, 공인 DNS 주소 고정, 리다이렉트 재검증, 응답 크기·시간 제한을 적용합니다. 내부 네트워크나 사용자 인증 정보를 사용하지 않습니다.

검증: 데스크톱 단위 테스트 112개, 서버 테스트 70개, Electron 대화·구매 카드 연동, 마스크 내부 원색 및 배경 투명도, 선택 영역 주변 장면과 영상 식별 분리 테스트 통과. 공개 서버에서 상품 인식 정상 응답을 확인했습니다.

한계: 실제 판매 검색 검증 당시 Gemini 검색 사용량 제한이 발생했습니다. 따라서 실시간 유사 상품 검색 성공률은 확인하지 못했습니다. 이때 제한 안내와 쇼핑 검색·Lens를 제공합니다. 판매 페이지의 자동 접근 제한이나 상품 사진 부재도 후보 확보를 막을 수 있습니다. 윤곽 모델과 AI의 판단은 오차가 있으므로 동일 모델이나 수치 유사율을 보장하지 않습니다.
