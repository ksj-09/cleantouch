# PC 0.1.32 — 화면 디자인 정리

위젯, 상품 목록, AI 대화에 공통 색상과 버튼 스타일을 적용했다. 짙은 남색 배경, 밝은 본문, 민트색 주요 동작으로 구분한다. 상품 사진은 원본 비율을 유지하고 잘리지 않게 표시한다.

- 시작 전에는 스캔 이후에만 사용할 수 있는 분석·멈춤 버튼을 숨긴다.
- 좁은 창에서는 상단 버튼과 검색창을 다음 줄로 배치한다.
- 화면 공유 중 AI 도구는 2열 격자로 정렬한다.
- 키보드 포커스 표시를 유지하고 운영체제의 동작 줄이기 설정을 따른다.
- 초기 화면의 중복 안내 영역을 줄이고 상품 결과 영역을 앞당긴다.

검증: Node 테스트 49개 통과. Electron continuous-analysis, place-chat, scene-grounding, review-workspace 모두 통과. 실제 미리보기의 위젯·대시보드·AI 대화 화면을 확인했다. 설치형·휴대형 빌드에 로컬 Gemini 키가 없는 것을 확인했으며, 패키지의 주요 소스가 현재 소스와 동일함을 검사했다. 버튼 배치 검증은 모든 버튼의 높이가 같고 최소 36px인지 확인한다.

이번 버전은 PC 디자인 변경이다. 모바일 APK 변경이나 상품 인식 정확도 개선을 주장하지 않는다. 0.1.31의 마스크 보정 필요성, 실제 기기 검증과 서비스 운영상의 제한은 남아 있다. 상용 완성판으로 선언하지 않는다.
