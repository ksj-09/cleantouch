## 0.1.25: Gemini 상품 검색 보조

선택한 윤곽 이미지 또는 찾은 상품 사진으로 검색하면 Lens 업로드와 Gemini 상품 인식을 병행합니다. Gemini는 선택 이미지의 종류와 색상으로 짧은 상품명을 정하며, Google 쇼핑 검색어는 화면에 표시하는 이름과 동일하게 만듭니다. 불확실한 결과에는 쇼핑 검색어를 만들지 않습니다. 상품 설명과 검색 버튼은 AI 챗봇에 표시되고 같은 상품에 대해 이어서 질문할 수 있습니다. AI 연결 실패는 Lens 검색을 막지 않습니다. 전체 스캔의 로컬 분석은 유지하고 사용자가 검색한 상품만 Gemini에 보냅니다.

## 0.1.24: 장소 분석 AI 챗봇

위젯의 **장소 분석 · AI에게 물어보기**를 누르면 확인된 영상 영역만 잘라서 보내고, “이 장소 분석해줘” 질문과 함께 챗봇을 엽니다. 오른쪽 아래 AI 버튼에서도 열 수 있습니다. 같은 사진으로 후속 질문과 지도 검색이 가능합니다. 영상 영역을 확인하지 못하거나 다른 창에 가려진 경우 전체 모니터 이미지를 보내지 않고 안내합니다. 닫으면 원래 위젯으로 돌아갑니다.

앱에는 사용자 Gemini 키가 필요하지 않습니다. 공개 Netlify 함수 `https://cleantouch-place-ai-20261006.netlify.app/v1/place-chat`가 운영자 키로 Gemini를 호출합니다. 장소 분석은 인터넷 연결이 필요하며 영상 이미지가 Gemini에 전송됩니다. 위치 정보는 전송하지 않으며 응답은 추정입니다. 중계 서버는 이미지를 파일로 저장하지 않습니다. 인스턴스별 요청 제한은 전체 서비스의 영구 사용량 제한이 아니므로, 운영자는 Netlify 및 Gemini 사용량을 함께 확인해야 합니다.

검증: `electron test/place-chat.cjs`, API 장소 분석 테스트 5개, `node test/public-place.mjs`(패키지 앱의 디버깅 포트 9226)가 자동 질문·후속 질문·지도 연결·재시도 및 공개 서버 연결을 확인합니다. Netlify 계정은 Free, Pro 체험판 아님을 확인했습니다.

## 0.1.19: 영상 재생 시간 연동과 로컬 이미지 AI

상품 등장 시점은 Edge/Chrome 확장 기능이 읽은 HTML video.currentTime을 기록합니다. 일시정지·되감기·영상 변경을 반영하며, 연결이 없거나 광고 중이면 시간 미확인으로 표시합니다. 스캔 경과 시간을 영상 시간으로 대체하지 않습니다. 앱 실행 시 사용자 계정의 Chrome/Edge NativeMessagingHosts에 로컬 실행 파일을 등록합니다. 통신은 Windows named pipe를 사용하며 외부 서버나 네트워크 포트를 열지 않습니다. 브라우저 확장 기능은 현재 개발자 모드로 한 번 설치해야 합니다. 앱의 ‘영상 시간 연결 안내’가 폴더와 설치 설명을 엽니다. 브라우저 스토어 배포는 포함되지 않습니다.

상품 후보 탐지 후 CLIP 이미지 AI가 64종의 설명과 사진을 비교하여 제목을 다시 결정합니다. 낮은 유사도나 모호한 순위는 ‘상품 후보’로 표시합니다. 반복 상품은 영상별 이미지 임베딩 유사도로 묶습니다. AI 분류는 추정이며 모든 상품 종류·브랜드를 인식하지 못합니다. 모델은 설치 파일에 포함되고 기기 내 Worker에서 실행합니다. 확장 기능이 선택한 활성 영상과 캡처한 화면이 일치하는지는 사용자 환경에서 확인해야 합니다.

검증: node --test test/video-timeline.test.cjs 및 node_modules/.bin/electron test/local-analysis.cjs. 통합 테스트는 실제 로컬 모델로 제목 분류·윤곽 추출·이미지 중복 처리·서버 없는 모두 분석을 확인하고, 캡처 메타데이터가 83초→83초(일시정지)→12초(이동)→null(연결 없음)로 기록되는지 확인합니다.

## 0.1.14: PC 상품 후보 영역 감지와 윤곽 추출 개선

PC에서도 휴대폰과 같은 상품 후보 영역 감지를 먼저 하고, 누른 위치 주변에서 가장 가능성 높은 마스크를 찾아 윤곽 PNG를 만듭니다. 한 번의 강한 픽셀 임계값에만 의존하지 않고 선택 지점의 신뢰도에 따라 마스크 경계를 계산합니다. 후보 감지나 분할에 실패하면 화면 전체를 Lens로 보내지 않습니다.

클릭 위치에 표시하던 원형 점을 제거했습니다. 모델이 반환하는 마스크에서 누른 위치에 연결된 물체만 남겨 실제 픽셀 윤곽을 초록색으로 표시하고, 투명 PNG 원본 바이트를 Lens에 전달합니다. 전체 화면에 가까운 마스크는 거부해 원본 캡처 전체가 검색되는 일을 막습니다. 윤곽 추출 실패 시 다시 선택하라는 안내를 표시합니다. 창 제목 아래 버전으로 새 빌드 여부를 확인할 수 있습니다.

## 0.1.12: 클릭한 상품의 윤곽 표시와 Lens 마스킹 보장

상품을 클릭하면 선택 지점만 표시하고, 초록색으로 채워진 실제 윤곽 마스크를 만든 뒤 그 PNG를 Lens로 보냅니다. 윤곽 추출에 실패하면 네모 사진으로 조용히 대체하지 않고 다시 선택하라는 안내를 표시합니다. 드래그 선택은 별도로 유지됩니다.

## 0.1.11: 탭한 상품 윤곽 마스킹

현재 장면에서 상품을 클릭하면 MediaPipe MagicTouch가 기기 안에서 해당 사물의 윤곽을 추출해 투명 배경 PNG로 만들고 Google Lens에 전달합니다. 이 빠른 검색 경로는 API 키나 분석 서버 연결 없이 동작합니다. 드래그하면 선택한 사각 영역을 검색합니다. Lens 창을 닫으면 위젯 화면으로 돌아옵니다.

화면 살펴보기 시작 → 위젯에서 현재 화면 분석 → 찾을 상품을 한 번 클릭 → 탭한 지점의 사물만 마스킹해 Lens로 자동 검색합니다. 사각형 자르기와 달리 배경을 투명하게 지웁니다. 상품 경계를 구분하기 어려운 장면에서는 탭 주변 사진으로 자동 대체합니다. 모델과 추론은 로컬에서 처리하고 선택한 이미지만 Google에 보냅니다.

전체 화면에서 상품별 결과와 캡처 시각을 볼 수 있습니다. 시각은 화면 공유 시작 후 경과 시간이며 영상의 재생 위치가 아닙니다. 시간을 직접 입력하지 않습니다. 소리와 영상 파일은 저장하지 않습니다. 전체 장면 분석과 앱 안 상품 목록은 현재 설정된 분석 서비스에 연결합니다.

Lens 결과는 앱의 별도 창에서 열립니다. Google 웹 페이지가 바뀌거나 자동 이미지 전달을 막으면 Lens 검색이 시작되지 않을 수 있습니다. 현재 분석 연결은 개발 PC의 LAN 서비스이며 공개 서비스는 아직 배포되지 않았습니다. 앱에 운영자 키를 넣지 않습니다.

```powershell
npm.cmd install
npm.cmd run start
npm.cmd run dist:win
```

출력: dist 폴더의 설치형 및 휴대형 exe. 현재 빌드는 코드 서명이 없습니다.

개발 앱을 --remote-debugging-port=9223으로 실행한 뒤 npm.cmd run test:smoke로 화면 캡처, 테스트 API 요청, 키/주소 입력 제거, 위젯 전환, 상품 선택 화면, 종료 시 자동 일괄 분석 방지를 확인합니다. 실제 AI 상품 정확도나 Android 오버레이를 검증하는 테스트는 아닙니다.
0.1.7: 시작 시 앱이 놓인 모니터의 전체 화면을 자동 캡처합니다. 위젯에는 30fps 목표의 MediaStream을 직접 표시하며, 상품 선택 시 별도로 현재 화면을 캡처합니다. Windows 캡처 제외 기능으로 CleanTouch 창이 반복해서 비치는 현상을 방지합니다. 다중 모니터는 시작 시 정한 화면을 세션 동안 유지합니다.

## Windows 자동 업데이트 (0.1.8)

Windows 설치형은 공개 GitHub 정식 릴리스를 시작 후 및 6시간 간격으로 확인합니다. 새 버전 알림에서 다운로드하고, 설치를 선택하면 앱을 재시작합니다. 캡처·분석 중이면 종료될 때까지 설치를 미루며 예약 취소가 가능합니다. 종료만으로 자동 설치하지 않습니다. 휴대형과 Android는 이 업데이트 경로의 대상이 아닙니다. 0.1.7 이전 사용자는 업데이트 기능이 들어 있는 설치형을 한 번 직접 설치해야 합니다.

빌드 후 node scripts/prepare-update-release.cjs를 실행하면 설치 파일 해시를 검증하고 GitHub 업데이트 정보에 맞는 파일명으로 dist/update-release에 파일을 준비합니다. 이 폴더의 설치 exe, exe.blockmap, latest.yml을 같은 GitHub 정식 릴리스에 올려야 합니다. 태그 v{package.json 버전}을 push하면 Windows 워크플로가 초안 릴리스를 만들도록 구성했습니다. 설치 검증 후 초안을 정식 공개해야 앱에 전달됩니다. prerelease와 이전 버전은 자동 적용하지 않습니다. 토큰과 운영자 API 키는 앱에 넣지 않습니다.

현재 검증: 설치 동의, 작업 중 대기, 예약 취소, 오류 시 설치 방지 단위 테스트 및 기존 캡처 실행 테스트 통과. 실제 설치된 이전 버전에서 새 버전으로 교체하는 종단 간 검증과 GitHub 정식 릴리스 공개는 아직 수행하지 않았습니다.
## 0.1.9: 위젯 현재 상품 / 큰 화면 전체 분석

위젯은 현재 장면의 선택 상품을 분석합니다. 시청하는 동안 5초 간격으로 장면을 메모리에 모읍니다. 큰 화면의 `모아둔 장면 전체 분석`은 캡처를 종료하고 수집한 모든 장면을 순서대로 분석합니다. 이전 장면의 상품 목록과 시작 후 발견 시각을 보여줍니다. 화면을 크게 여는 것만으로 API 요청하지 않습니다.

선택 영역 분석은 전체 장면 분석 완료로 취급하지 않습니다. 전체 분석에서 같은 장면의 다른 상품도 분석합니다. 성공한 전체 장면은 재개 시 건너뛰고 실패한 장면부터 다시 처리합니다. 요청 간 2.1초 간격 및 기존 한도 초과 재개 처리를 유지합니다.

오래된 장면을 주기적으로 삭제하던 24장 제한은 제거했습니다. 메모리 250MB에 도달하면 새 장면 수집을 멈추고 안내합니다. 짧게 지나가는 상품은 5초 표본 사이에 빠질 수 있습니다. 장면은 앱 종료 또는 새로 시작 때 지워집니다. 이번 변경은 Windows 앱에 적용되었습니다.
