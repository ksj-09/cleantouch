# CleanTouch 발표 한 장 요약

## 시작

> CleanTouch는 쇼츠를 보다가 궁금한 상품이 등장하면 플로팅 버튼 한 번으로 화면을 분석하고 쇼핑 검색으로 연결하는 앱입니다.

## 1. 문제

- 상품명·가격·링크가 영상을 가림
- 정보가 없으면 상품을 직접 검색하기 어려움
- **원할 때만 정보를 보여주자**

## 2. 아이디어 변화

- 처음: 영상 속 상품 직접 터치 SDK
- 문제: 외부에서 YouTube·Instagram 플레이어 수정 불가
- 변경: Android 화면 공유 + 플로팅 스캔 버튼

> 플랫폼이 기능을 넣어 주기를 기다리지 않고 사용자가 직접 원하는 순간을 스캔하도록 바꿨습니다.

## 3. 사용 흐름

`스캔 모드 시작 → 영상 앱 이동 → 플로팅 버튼 → 상품 인식 → 쇼핑 검색 → 판매 사이트`

- 자동 인식 실패 시 상품 위치 직접 지정
- 작게·보통·넓게 영역 선택

## 4. 현재 구현

- 실제 Android 앱
- 실제 화면 한 장 캡처
- AI 상품 특징 분석
- 네이버 쇼핑·Google Shopping 연결
- 화면 회전·오류·무료 한도 대응
- 이미지 임시 처리 후 삭제

## 5. 테스트 결과

- 작은 검은색 가방 → 검정색 미니 숄더백 계열 인식
- 쇼핑 검색 경로 2개 생성
- Android 빌드·린트 통과
- 검색 서버 테스트 16개 통과
- 회전 시 중복 검색 없음

## 6. 고객과 수익

- 사용자: 무료
- 돈을 내는 고객: 쇼핑몰, 브랜드, 숏폼 커머스 사업자
- 수익: SDK 라이선스, 상품 DB 연동, 분석 기능, 제휴 수수료
- 연 2,400만 원 + 구매액 2%는 **검증 전 가격 가정**

## 7. 현재 한계

- 무료 AI 사용량 제한
- 개발 PC에서 검색 서버 실행
- 정확한 동일 상품·가격은 제휴 상품 DB 필요
- iPhone은 별도 공유 메뉴 방식 필요
- 스토어의 화면 공유·오버레이 정책 검토 필요

## 8. 다음 단계

1. 가방 카테고리 집중
2. 실제 쇼츠 50개 정확도 측정
3. 사용자 20~50명 테스트
4. 기존 상품 스티커와 완주율·클릭률 비교
5. HTTPS 클라우드 서버와 상품 DB 연결

## 끝맺음

> CleanTouch의 핵심은 상품 정보를 더 많이 보여주는 것이 아니라, 사용자가 원하는 순간에만 자연스럽게 연결하는 것입니다.
