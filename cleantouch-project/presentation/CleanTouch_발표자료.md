# CleanTouch 발표자료

## 발표 제목

**CleanTouch — 영상 속 궁금한 상품을 원하는 순간 바로 찾는 서비스**

### 한 문장 소개

유튜브 쇼츠나 인스타그램 릴스를 보다가 궁금한 옷, 가방, 신발이 나오면 화면 위의 버튼을 눌러 상품을 인식하고 쇼핑 검색으로 연결하는 안드로이드 서비스입니다.

---

# 1. 발표 전체 흐름

권장 발표 시간은 **6~7분**, 시연은 **1~2분**입니다.

1. 문제와 계기
2. 아이디어가 바뀐 과정
3. 최종 서비스 사용 방식

5. 실제 테스트 결과
6. 고객과 수익 모델
7. 한계와 다음 단계

# 2. 슬라이드별 발표 내용

## 슬라이드 1. 문제 제기

### 화면에 넣을 문구

**상품 정보 때문에 정작 영상이 가려진다**

- 쇼츠 위 상품명·가격·링크가 영상 내용을 가림
- 정보가 없으면 궁금한 상품을 다시 검색해야 함
- 사용자가 원하는 순간에만 정보가 필요함

### 발표 대본

> 쇼츠 영상을 보다 보면 상품명이나 가격, 구매 링크가 화면 위에 계속 떠 있는 경우가 있습니다. 정보를 바로 볼 수 있다는 장점은 있지만, 옷의 모양이나 영상의 중요한 장면을 가려 오히려 시청을 방해하기도 합니다. 반대로 아무 정보가 없으면 영상 속 가방이나 옷이 궁금해도 직접 검색하기 어렵습니다. 그래서 정보를 계속 보여주는 방식이 아니라, 사용자가 궁금할 때만 상품을 찾는 방식을 생각했습니다.

---

## 슬라이드 2. 아이디어가 바뀐 과정

### 화면에 넣을 문구

**영상에 기능을 넣는 방식 → 사용자가 직접 스캔하는 방식**

| 초기 구상 | 현재 구상 |
| --- | --- |
| 영상 속 상품을 직접 터치 | 플로팅 버튼을 눌러 현재 화면 스캔 |
| 영상 서비스가 SDK를 설치해야 함 | YouTube·Instagram 등 다른 앱 위에서 사용 |
| 상품 위치를 미리 등록 | AI가 캡처 화면에서 상품을 분석 |

### 발표 대본

> 처음에는 딤팩 기술을 이용해 영상 속 상품 자체를 터치하면 정보가 나오는 SDK를 생각했습니다. 하지만 외부 회사가 유튜브나 인스타그램 앱의 영상 플레이어를 마음대로 수정할 수 없다는 현실적인 문제가 있었습니다. 피드백을 반영해 방향을 바꿨습니다. 이제는 사용자가 CleanTouch를 실행한 뒤 평소 사용하던 영상 앱으로 돌아가고, 궁금한 상품이 보일 때 플로팅 버튼으로 그 순간을 스캔합니다. 따라서 영상 제작자나 플랫폼이 상품 위치를 미리 등록하지 않아도 됩니다.

### 강조할 점

- 아이디어를 포기한 것이 아니라 **플랫폼 적용 문제를 해결하도록 사용 방식을 바꾼 것**입니다.
- 현재 앱은 딤팩을 직접 탑재한 완성형 SDK가 아니라, 딤팩 아이디어에서 발전한 **사용자 주도형 스캔 앱**입니다.

## 슬라이드 3. CleanTouch 사용 순서

### 화면에 넣을 문구

1. CleanTouch에서 스캔 모드 시작
2. Android 전체 화면 공유 허용
3. YouTube·Instagram 등으로 이동
4. 궁금한 상품이 보일 때 플로팅 버튼 선택
5. 상품 인식 결과 확인
6. 네이버 쇼핑·Google Shopping으로 이동

### 발표 대본

> 사용법은 단순합니다. CleanTouch에서 스캔 모드를 시작하고 Android의 전체 화면 공유를 한 번 허용합니다. 그다음 유튜브나 인스타그램으로 이동합니다. 영상 속에서 궁금한 상품이 보일 때 청록색 버튼을 누르면, 버튼이 잠시 사라지고 그 순간의 화면 한 장만 캡처합니다. AI가 상품의 종류, 색상, 형태를 분석하고 네이버 쇼핑과 Google Shopping 검색 결과로 연결합니다.

> 상품이 너무 작아서 자동으로 찾지 못하면 사용자가 상품 위치를 직접 지정할 수 있습니다. 작게, 보통, 넓게 중 영역 크기를 고른 뒤 상품이 있는 부분을 선택하면 확대된 영역으로 다시 검색합니다.

---

## 슬라이드 4. 현재 구현된 기능

### 화면에 넣을 문구

**단순 화면 시안이 아니라 실제 Android 앱과 검색 서버를 구현**

- 다른 앱 위에 표시되는 이동 가능한 플로팅 버튼
- 버튼을 누른 순간의 화면 캡처
- 작은 상품 위치 지정 및 확대 검색
- AI 기반 상품 특징 분석
- 네이버 쇼핑·Google Shopping 연결
- 결과가 없는 경우 자동 위치 지정 화면
- 화면 회전과 연속 검색 대응
- 캡처 이미지 임시 처리 후 자동 삭제

### 발표 대본

> 처음에는 웹으로 사용 흐름을 보여주는 시제품을 만들었고, 이후 실제 Android 앱으로 발전시켰습니다. 현재는 다른 앱 위에 플로팅 버튼을 띄우고, 사용자가 버튼을 누른 순간 화면을 캡처해 검색 서버로 보내는 과정이 실제로 동작합니다. 결과가 없을 때는 상품 위치를 직접 지정할 수 있고, 화면을 회전해도 기존 결과가 유지됩니다. 캡처 파일은 검색이 끝나면 삭제하며 서버도 업로드 이미지를 디스크에 보관하지 않습니다.

## 슬라이드 5. 실제 테스트 결과

### 화면에 넣을 문구

**작게 보이는 가방도 실제 인식 성공**

- 테스트 화면: 전체 화면 중앙의 작은 검은색 가방
- 인식 결과: `검정색 미니 숄더백` 계열
- 쇼핑 검색 경로 2개 생성
- Android 빌드 및 린트 통과
- 검색 서버 자동 테스트 16개 통과
- 회전 전후 중복 AI 요청 없이 결과 유지

### 발표 대본

> 실제 테스트에서는 휴대전화 화면 중앙에 작게 보이는 검은색 가방을 스캔했습니다. CleanTouch가 이를 검정색 미니 숄더백으로 인식했고, 네이버 쇼핑과 Google Shopping 검색 경로를 만들었습니다. Android 빌드와 코드 검사도 통과했고, 서버에서는 이미지 형식, 손상된 파일, 잘못된 AI 응답, 일시적인 외부 서비스 오류 등을 포함한 자동 테스트 16개가 통과했습니다.

> 테스트 과정에서 화면을 회전하면 결과를 다시 검색해 무료 사용량을 낭비하는 문제도 발견했습니다. 현재는 회전할 때 기존 결과만 다시 배치하고 AI를 재호출하지 않도록 수정했습니다.

## 슬라이드 6. 개인정보와 안정성

### 화면에 넣을 문구

**항상 녹화하는 방식이 아니라 사용자가 누른 순간만 처리**

- Android 시스템 화면 공유 동의 필요
- 스캔 버튼을 누른 순간 한 프레임만 파일로 생성
- 서버 디스크에 이미지 저장하지 않음
- 손상된 이미지와 잘못된 서버 응답 차단
- 사용자가 알림에서 언제든 스캔 모드 종료

### 발표 대본

> 화면 공유 세션 자체는 스캔 모드 동안 유지되지만, 실제 이미지 파일을 만들고 서버에 보내는 시점은 사용자가 버튼을 누른 순간입니다. 임시 캡처 파일은 검색 후 삭제하고 검색 서버도 이미지를 디스크에 저장하지 않습니다. 사용자는 Android 알림에서 언제든 스캔 모드를 종료할 수 있습니다. 다만 금융 앱이나 보안 영상처럼 운영체제가 캡처를 막은 화면은 검색할 수 없습니다.

---

## 슬라이드 7. 기존 이미지 검색과의 차이

### 화면에 넣을 문구

**영상 시청 흐름을 끊지 않는 상품 검색**

- 별도로 스크린샷을 찍고 검색 앱을 열 필요가 없음
- 영상 위에 상품 정보가 계속 표시되지 않음
- 모든 상품을 미리 등록하지 않아도 됨
- 작은 상품은 사용자가 위치를 직접 지정 가능

### 발표 대본

> Google Lens 같은 이미지 검색 서비스도 있지만, 보통 스크린샷을 찍고 검색 앱을 열거나 이미지를 가져와야 합니다. CleanTouch는 영상 앱 위에 있는 버튼을 한 번 누르면 바로 검색 결과가 열리는 흐름에 집중했습니다. 또한 상품 정보가 영상 위에 계속 떠 있지 않기 때문에 원래 콘텐츠를 가리지 않습니다.

---

## 슬라이드 8. 고객과 수익 모델

### 화면에 넣을 문구

**사용자는 무료, 커머스 사업자가 비용을 내는 구조**

### 비용을 낼 고객 후보

- 자체 숏폼 피드를 운영하는 쇼핑몰·홈쇼핑 앱
- 숏폼 커머스 플레이어를 공급하는 영상 솔루션 회사
- 패션 브랜드와 상품 데이터 보유 사업자

### 수익 모델 후보

- 기업용 SDK·관리 화면 연간 라이선스
- 상품 DB 연동 및 분석 기능 이용료
- 검색 결과 상단 노출 광고
- 구매 발생 시 제휴 수수료

### 발표 대본

> 일반 사용자는 무료로 사용하고, 돈을 내는 고객은 쇼핑몰과 브랜드, 영상 커머스 사업자로 설정했습니다. 이들은 영상 시청을 방해하지 않으면서 상품 클릭과 구매 전환을 높이기 위해 비용을 낼 수 있습니다. 수익 모델은 기업용 SDK 라이선스, 상품 DB 연동비, 클릭·구매 분석 기능, 제휴 구매 수수료입니다.

> 기존 워크시트에서는 고객사당 연 2,400만 원과 구매액의 2% 수수료를 가정했습니다. 이 숫자는 확정 가격이 아니라 고객 인터뷰와 실증을 통해 검증해야 하는 초기 가정입니다.

## 슬라이드 9. 현재 한계

### 화면에 넣을 문구

**기술 시제품은 동작하지만 운영 서비스에는 추가 단계가 필요**

- 현재는 무료 AI 공급자의 사용량 제한이 있음
- 검색 서버가 개발 PC에서 실행됨
- 정확한 브랜드·모델은 화면에 근거가 있을 때만 확인 가능
- 현재 결과는 동일 상품 확정이 아니라 쇼핑 검색어 기반 연결
- iPhone은 Android와 같은 플로팅 버튼 방식이 어려움
- Google Play 출시 전 오버레이·화면 공유 정책 검토 필요

### 발표 대본

> 현재 버전은 실제 동작하는 기술 시제품이지만 많은 사람이 바로 사용할 수 있는 운영 서비스 단계는 아닙니다. 무료 AI 사용량 제한이 있고 서버도 개발 PC에서 실행되고 있습니다. 또한 화면에서 브랜드와 모델명이 보이지 않으면 정확한 동일 상품을 확정할 수 없기 때문에 현재는 상품 특징을 이용한 쇼핑 검색으로 연결합니다.

> 정확한 가격과 재고까지 앱 안에서 제공하려면 제휴 쇼핑몰의 상품 카탈로그와 이미지 검색 시스템이 필요합니다. iPhone은 다른 앱 위에 버튼을 자유롭게 띄우기 어렵기 때문에 스크린샷 공유 메뉴를 이용하는 별도 방식이 필요합니다.

## 슬라이드 10. 다음 단계

### 화면에 넣을 문구

1. 가방 카테고리부터 정확도 측정
2. 실제 쇼츠 50개로 성공률·검색 시간 기록
3. 사용자 20~50명 테스트
4. 화면 가림, 클릭률, 구매 페이지 도달률 비교
5. HTTPS 클라우드 서버 구축
6. 첫 상품 DB·커머스 파트너 연결

### 발표 대본

> 다음 단계에서는 모든 상품을 한 번에 지원하기보다 가방처럼 형태가 비교적 분명한 카테고리부터 정확도를 측정하겠습니다. 실제 쇼츠 50개에서 상품 크기와 위치별 성공률, 검색 시간, 위치 재지정 비율을 기록할 계획입니다. 이후 사용자 테스트를 통해 기존 상품 스티커 방식보다 영상 몰입도를 높이면서도 상품 클릭률을 유지할 수 있는지 검증해야 합니다.

> 사업화를 진행한다면 서버를 HTTPS 클라우드 환경으로 이전하고, 첫 커머스 파트너의 상품 DB를 연결해 정확한 상품과 가격을 보여주는 단계로 발전시키겠습니다.

# 3. 실제 시연 순서

## 시연 전 준비

- PC와 스마트폰을 같은 와이파이에 연결
- 검색 서버 상태 확인
- 앱 아래 버전이 `CleanTouch 0.2.1-debug`인지 확인
- 무료 AI 한도가 남아 있는지 한 번만 사전 검사
- 실패에 대비해 실제 결과 화면 이미지를 발표 자료에 넣어 두기

## 시연 멘트와 행동

1. **CleanTouch 앱 실행**
   - “먼저 CleanTouch에서 스캔 모드를 시작하겠습니다.”
2. **스캔 모드 시작 선택**
   - “Android가 전체 화면 공유 여부를 직접 확인합니다.”
3. **YouTube·Instagram 또는 준비한 영상으로 이동**
   - “이제 평소처럼 영상을 봅니다. 영상 위에는 상품 정보가 계속 표시되지 않습니다.”
4. **가방이 보이는 순간 플로팅 버튼 선택**
   - “궁금한 상품이 보이는 순간 이 버튼만 누릅니다.”
5. **결과 화면 확인**
   - “화면에서 상품 특징을 분석해 쇼핑 검색 경로를 보여줍니다.”
6. **위치 지정 기능 설명**
   - “상품이 작거나 여러 개면 위치를 다시 지정해 확대 검색할 수 있습니다.”
7. **가격·판매처 비교하기 선택**
   - “선택한 상품 검색 결과에서 가격과 판매처를 비교할 수 있습니다.”

## 시연 중 피해야 할 행동

- 짧은 시간에 같은 상품을 여러 번 검색하지 않기
- 알림, 개인정보, 비밀번호가 보이는 화면에서 스캔하지 않기
- 정확한 동일 상품이라고 단정하지 않기
- 무료 AI가 실패하면 반복 호출하지 말고 준비한 결과 화면으로 설명 이어가기

# 4. 예상 질문과 답변

## Q1. 유튜브나 인스타그램에 직접 기능을 넣은 것인가요?

> 아닙니다. 외부 회사가 해당 앱의 플레이어를 수정할 수 없기 때문에 Android의 사용자 승인 화면 공유와 플로팅 버튼을 이용했습니다. 자체 숏폼 플레이어를 가진 기업과 협업하는 경우에는 별도 SDK 방식도 가능합니다.

## Q2. 화면을 계속 녹화하나요?

> 스캔 모드 동안 Android 화면 공유 세션은 유지됩니다. 하지만 실제로 파일을 만들고 서버로 전송하는 것은 사용자가 플로팅 버튼을 누른 순간의 한 화면입니다. 임시 파일은 검색 후 삭제하고 서버도 이미지를 디스크에 저장하지 않습니다.

## Q3. 정확히 같은 상품을 찾을 수 있나요?

> 현재 무료 AI 버전은 상품의 종류, 색상, 형태를 분석해 쇼핑 검색으로 연결합니다. 화면에 브랜드나 모델명이 명확히 보이지 않으면 동일 상품이라고 단정하지 않습니다. 정확한 동일 상품 검색에는 제휴 상품 DB와 이미지 벡터 검색이 필요합니다.

## Q4. Google Lens와 무엇이 다른가요?

> 이미지 검색 기술 자체보다 영상 시청 중 바로 사용하는 흐름에 차이가 있습니다. 스크린샷 저장, 앱 이동, 이미지 불러오기 과정을 줄이고 영상 위에 정보를 계속 표시하지 않는 것이 핵심입니다.

## Q5. 누가 돈을 내나요?

> 일반 사용자는 무료로 사용하고, 상품 노출과 구매 전환을 원하는 쇼핑몰, 브랜드, 숏폼 커머스 솔루션 사업자가 상품 DB 연동, 분석 기능, SDK 라이선스와 제휴 수수료 형태로 비용을 내는 구조를 생각하고 있습니다.

## Q6. 지금 많은 사람이 사용할 수 있나요?

> 현재는 로컬 검색 서버와 무료 AI를 사용하는 검증 단계입니다. 다수 사용자를 받으려면 HTTPS 클라우드 서버, 충분한 AI 사용량, 사용자 인증, 모니터링과 쇼핑몰 상품 DB가 필요합니다.

## Q7. 아이폰에서도 가능한가요?

> iOS는 다른 앱 위에 플로팅 버튼을 자유롭게 띄우기 어렵습니다. 초기 iPhone 버전은 스크린샷 공유 메뉴에서 CleanTouch를 선택하거나 이미지를 앱으로 가져오는 방식이 현실적입니다.

## Q8. 상품이 여러 개 나오면 어떻게 하나요?

> 자동 인식 결과가 없거나 다른 상품을 찾았을 때 상품 위치 지정 화면을 엽니다. 사용자가 작게, 보통, 넓게 중 영역을 선택하고 원하는 상품의 가운데를 지정해 다시 검색할 수 있습니다.

# 5. 1분 요약 발표

> CleanTouch는 유튜브 쇼츠나 인스타그램 릴스를 보다가 궁금한 상품이 나왔을 때, 화면 위의 버튼을 눌러 바로 검색하는 안드로이드 서비스입니다. 기존 쇼츠 커머스는 상품명과 가격이 영상 위에 계속 떠 있어 콘텐츠를 가리는 문제가 있었습니다. CleanTouch는 평소에는 아무 정보도 띄우지 않고 사용자가 원하는 순간에만 화면 한 장을 분석합니다.
>
> 처음에는 영상 서비스가 SDK를 직접 설치하는 방식을 생각했지만 유튜브나 인스타그램을 외부에서 수정할 수 없다는 한계가 있었습니다. 그래서 Android의 화면 공유와 플로팅 버튼을 이용하는 사용자 주도형 방식으로 바꿨습니다. 현재 실제 Android 앱과 검색 서버를 구현했고, 화면 중앙에 작게 보이는 가방을 검정색 미니 숄더백으로 인식해 네이버 쇼핑과 Google Shopping으로 연결하는 데 성공했습니다. Android 빌드와 코드 검사를 통과했고 서버 자동 테스트 16개도 완료했습니다.
>
> 다음 단계는 가방 카테고리부터 실제 영상 50개와 사용자 20명 이상으로 정확도와 클릭률을 검증하고, 클라우드 서버와 제휴 상품 DB를 연결하는 것입니다.

# 6. 20초 핵심 소개

> CleanTouch는 쇼츠를 보다가 궁금한 상품이 등장하면 플로팅 버튼 한 번으로 현재 화면을 분석하고 쇼핑 검색으로 연결하는 앱입니다. 영상 위에 상품 정보를 계속 띄우지 않아 콘텐츠를 가리지 않고, 작은 상품은 사용자가 위치를 지정해 다시 검색할 수 있습니다. 현재 실제 Android 앱과 AI 검색 서버까지 구현해 작은 가방 인식을 검증했습니다.

# 7. 발표 마무리 문장

> CleanTouch의 핵심은 상품 정보를 더 많이 보여주는 것이 아니라, 사용자가 원하는 순간에만 자연스럽게 연결하는 것입니다. 앞으로 실제 영상과 사용자 테스트를 통해 이 방식이 영상 몰입도를 지키면서 구매 전환에도 도움이 되는지 검증하겠습니다.
