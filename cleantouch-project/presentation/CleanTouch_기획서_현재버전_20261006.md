# CleanTouch 현재 버전 기획서

Windows 0.1.26 / Android 0.4.8 · 2026-10-06

## 1. CleanTouch 서비스 기획서

영상 속 상품과 장소를 선택하고, AI와 대화하며 탐색하는 서비스

일반 사용자는 API 키 발급 없이 이용한다. 구매 연결은 검색·판매처 탐색이며 앱 내 자동 결제는 아니다.

## 2. 목차

서비스 목표부터 현재 구현과 다음 개선 과제까지

표지·목차 포함 14장. 기능 소개와 검증 상태를 함께 제시한다.

## 3. 서비스 목표: 시청 중 발견을 탐색으로 연결

검색어를 고민하거나 사진을 저장하는 수고를 줄입니다.

대상과 문제: 유튜브·인스타그램을 보는 일반 사용자

마음에 드는 옷·가방·신발·장난감 발견
지나간 장면을 다시 찾기 어려움
이름 검색만으로 다른 상품이 나옴

제공하는 가치: 작은 위젯으로 필요한 순간에 선택

상품 사진·짧은 이름·AI 설명 확인
상품과 장소에 대해 이어서 질문
비슷한 상품과 판매처로 이동

정보 확인과 검색을 돕는 제품이다. 정확한 모델·동일 상품·주소를 항상 확정하는 서비스로 표현하지 않는다.

## 4. 모바일 사용 흐름

시청할 때는 작게, 분석과 대화가 필요할 때는 펼칩니다.

상품 터치 윤곽 추출은 구현됐으나 최신 에뮬레이터 시험에서 시간 초과가 발생했다. 직접 영역 선택 → 실제 상품 AI → 쇼핑 버튼 경로는 통과했다. 외부 검색·판매 페이지에서는 화면이 전환된다.

## 5. 위젯은 지금의 상품, 큰 화면은 지금까지의 상품

현재 화면 분석과 모두 분석의 역할을 분리합니다.

현재 화면 상품 찾기: 위젯에서 원하는 순간에 실행
상품을 클릭·터치해 선택
선택한 상품의 사진·윤곽 확인
AI 설명·Lens·쇼핑 검색으로 연결

모두 분석·큰 화면: 스캔을 일시정지하고 모은 장면 분석
지나간 상품도 목록에서 확인
사진·영상별 등장 기록 제공
반복 상품 통합 후 스캔 계속하기

스캔 세션 밖의 과거 영상까지 분석하지 않는다. 일정 간격 수집 사이의 짧은 등장은 놓칠 수 있다. 중복 제거는 유사도 기반이며 완전한 동일 상품 식별을 보장하지 않는다.

## 6. 상품 AI 챗봇: 선택 → 설명 → 추가 질문

Lens를 거치지 않고 챗봇에서 상품 분석을 시작할 수 있습니다.

상품 분석: 챗봇의 “상품 분석” 선택
현재 장면에서 원하는 상품 지정
Gemini가 종류·색상·판단 근거 설명
짧은 이름: 청바지 · 검은 가방
모바일에는 직접 영역 선택 경로 제공

추가 질문과 쇼핑: “비슷한 상품을 어떻게 찾을까?”
“어떤 특징을 확인하면 좋을까?”
선택한 사진과 대화 맥락으로 답변
표시된 상품명 그대로 쇼핑 검색
불확실하면 임의 검색어 생성 억제

상품 인식 API는 신뢰도가 낮으면 검색어와 쇼핑 링크를 비운다. 서버에서 쇼핑 검색어를 표시 이름과 동일하게 제한한다. 챗봇은 실시간 판매 검색 결과를 읽는 구매 에이전트가 아니다.

## 7. 장소 AI 챗봇: 보이는 단서로 후보 제시

궁금한 풍경·거리·장소를 영상 장면으로 질문합니다.

장소 분석 흐름: 챗봇에서 “장소 분석” 선택
영상 영역만 확인해 전송
“이 장소 분석해줘” 자동 질문
간판·건물·도로·풍경 단서 설명
이어서 필요한 단서와 위치 질문

결과와 확인 방법: 근거가 있을 때 장소 후보 제공
후보를 지도 검색으로 연결
불충분하면 알 수 없다고 안내
실제 GPS·촬영 위치는 전송하지 않음
정확한 주소·영업시간은 별도 확인

모바일 영상 경계를 확실하게 찾지 못하면 로컬 영역 확인을 먼저 거친다. 지도 링크는 후보명 검색이며 주소가 검증됐다는 의미가 아니다.

## 8. 구매 연결: 이미지 검색 + 같은 이름의 쇼핑 검색

엉뚱한 키워드로 다른 상품이 검색되는 문제를 줄입니다.

Google Lens: 선택한 상품 사진을 이미지 검색으로 전달
비슷한 외형의 제품 탐색
이미지 저장·수동 업로드 단계 축소
PC에서는 Lens와 AI 인식 병행
외부 서비스 오류 시 재시도 안내

Google 쇼핑 검색: AI 표시 이름과 검색어를 일치시킴
“보라색 광선검” → 같은 단어로 검색
숨겨진 소재·핏·종류를 임의 추가하지 않음
결과에서 판매 페이지로 이동
실제 가격·재고·동일 상품 여부 확인

최근 외부 Google Lens 업로드 검증에서 HTTP 502가 발생했다. Lens 연결 구현과 검색 결과 도달 성공을 구분한다. 상품 AI와 쇼핑 링크는 별도로 검증됐다.

## 9. 수집 장면과 영상 등장 시간

스캔 경과 시간 대신 영상별 등장 시점을 보여주는 방향입니다.

장면 수집과 목록: 일정 간격으로 영상 장면 수집
영상·소리 전체를 파일로 녹화하지 않음
모두 분석은 수집한 장면까지 처리
사진과 반복 등장 기록을 함께 표시
목표: 짧게 지나간 상품의 누락 감소

시간 보정과 영상 구분: 화면 시간·재생 상태를 읽어 보정
영상 변경·일시정지·이동 인식 로직
확인되지 않은 시점은 추정으로 표시
이전 영상의 기록은 유지
쇼츠·되감기·앱별 동작 추가 검증

PC 화면 OCR·미디어 세션 및 Android 로컬 OCR·타임라인 로직이 구현돼 있다. 연속 장면 수집은 성능과 메모리를 고려한 후속 개선이다.

## 10. 운영 구조: 기기 내 분석 + Gemini 대화

일반 사용자는 앱만 설치하고, 운영자가 AI 연결을 관리합니다.

사용자 기기: 화면 공유·위젯
장면 수집·상품 목록
후보 탐지·윤곽·시간 추정
기본 모두 분석은 로컬
선택한 사진과 질문 전송

공개 AI 중계: Netlify 함수로 연결
Gemini 키는 서버에서 관리
요청 크기·빈도 제한
앱에 운영자 키 미포함
운영자 계정 사용량 합산

AI와 검색: Gemini: 상품·장소·대화
Lens: 비슷한 이미지 검색
쇼핑: 같은 상품명 검색
지도: 장소 후보 확인
AI 대화와 외부 검색은 인터넷 필요

Netlify 중계가 공개 배포됐다. 무료 호스팅·AI 서비스는 무제한 운영을 의미하지 않으며 운영자 사용량과 제공자 한도를 관리해야 한다. 현재 서버 사용량 제한은 전역 영속 예산 장치가 아니므로 추가 보완이 필요하다. 개인 키 입력은 일반 사용자 흐름에 없다.

## 11. Windows 0.1.26: 챗봇 상품 분석 진입 추가

설치형·포터블 제공 · 실제 배포 파일의 챗봇 통합 테스트 통과

현재 제공 기능: 화면 스캔·위젯·상품 선택
모두 분석·반복 상품 통합·시간 기록
챗봇에서 상품 / 장소 직접 선택
상품 분석은 Lens 실행 없이 진입 가능
AI 설명·추가 질문·쇼핑 링크

확인한 동작: 소스와 패키징된 앱 통합 검사 통과
상품 선택 화면 진입 및 AI 결과 표시
쇼핑 검색어와 표시 상품명 일치
대화 이어가기·오류 재시도
설치 파일의 운영자 키 미포함 확인

Windows 최신 UI 통합 검증에는 모의 IPC가 사용됐고, 앞선 공개 중계의 실제 상품·후속 대화 검증 기록이 있다. Lens 외부 서비스 성공을 이 테스트 결과로 대체하지 않는다.

## 12. Android 0.4.8: 상품·장소 챗봇 함께 제공

모바일 사용성을 우선하며 자동 윤곽 인식에는 대체 경로를 마련했습니다.

이번 버전의 개선: 홈의 AI 챗봇 진입을 상품·장소로 변경
챗봇 안에 상품 / 장소 버튼 추가
상품 터치 선택과 직접 영역 선택
선택 사진으로 AI 설명·쇼핑 검색
사진이 버튼을 가리는 표시 문제 수정

검증과 보완 범위: 실제 공개 AI 호출 검증
영역 선택 → 상품 결과 → 쇼핑 버튼 통과
상품·장소 전환 동작 확인
자동 윤곽은 에뮬레이터 시간 초과 발생
갤럭시 A15 실기기 안정성 추가 확인

Android 16 에뮬레이터의 직접 영역 선택 기반 상품 분석 시험이 44.025초에 1개 통과했다. 이전 Lens→상품 챗봇 후속 질문은 별도로 검증됐으며 현재 자동 터치 윤곽은 통과 결과가 없다. 과거 A15 종료 증상 해결을 확정하지 않는다.

## 13. 현재 구현과 검증 상태

구현된 기능과 추가 확인이 필요한 부분을 함께 관리합니다.

외부 Lens 502와 모바일 자동 윤곽 시간 초과는 남은 이슈다. 상품 AI·직접 영역 선택·쇼핑·챗봇 전환은 독립적인 검증 결과로 관리한다.

## 14. 다음 작업: 안정성 → 정확도 → 탐색 편의

새 기능 확대보다 실제 시청 흐름에서의 성공률을 우선합니다.

기간·성능·비용 목표를 임의로 약속하지 않는다. 현재 사용자 우선순위는 모바일 중심의 쉬운 선택과 구매 탐색이다.
