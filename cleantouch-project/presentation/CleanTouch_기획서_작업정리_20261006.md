# CleanTouch 기획서·작업 정리

기준일: 2026-10-06. 열려 있던 메모장의 저장된 간단기획서와 현재 소스·검증 기록을 반영했습니다.

## 1. CleanTouch 서비스 기획서

영상 속 상품을 발견하는 순간부터, 비슷한 상품과 구매처를 찾기까지

일반 사용자가 API 키 발급이나 분석 서버 설정 없이 이용하는 것이 제품 방향이다. 현재 구매 연결은 Lens 이미지 검색이며 직접 결제 기능은 없다.

## 2. 목차

서비스의 목적, 사용 방법, 구현 상태와 다음 작업을 순서대로 설명합니다.

표지와 목차를 포함해 총 12장. 구현된 기능과 목표 기능을 구분한다.

## 3. 서비스 목표와 사용자

검색어를 고민하거나 이미지를 직접 저장하는 수고를 줄입니다.

사용자와 상황: 유튜브·인스타그램 영상을 보는 일반 사용자

옷, 가방, 신발, 장난감 등
영상 속 마음에 드는 상품을 발견한 순간

제공하려는 경험: 시청 중 작은 위젯으로 상품 선택

상품 사진과 핵심 키워드 확인
비슷한 제품과 판매처 탐색

발견·선택·확인은 시청 화면에서 진행하고 외부 이미지 검색 및 판매 사이트 이동 시 다른 화면으로 전환된다. 판매처 탐색을 돕는 서비스이며 동일 상품 식별을 항상 보장하지 않는다.

## 4. 모바일 사용 흐름

영상 시청 중 필요한 순간에만 위젯을 펼칩니다.

이 슬라이드는 목표 사용 흐름이며 실제 모바일 윤곽 인식과 스캔 유지 안정성에는 개선이 필요하다. 원형 시작 버튼 및 권한 요청의 기획 의도를 반영했다.

## 5. 위젯은 지금의 상품, 큰 화면은 지금까지의 상품

현재 화면 분석과 모두 분석의 역할을 분명하게 나눕니다.

현재 화면 상품 찾기: 시청 중 위젯에서 실행
원하는 상품을 한 번 터치·클릭
선택한 상품의 영역과 윤곽 확인
상품 부분만 이미지 검색으로 전달

모두 분석·큰 화면 보기: 스캔을 일시정지하고 모은 장면 분석
이미 지나간 상품도 목록에서 확인
사진·등장 시점·저장 장면 보기
확인 후 스캔 계속하기

모두 분석은 영상 전체를 나중에 다운로드해 분석하는 방식이 아니라 해당 스캔 세션에서 수집한 장면을 대상으로 한다. 표본 사이에 짧게 나타난 상품은 놓칠 수 있다.

## 6. AI가 상품을 찾고, 사람은 선택 결과를 확인

사각형 영역보다 상품의 실제 윤곽을 잡는 것이 핵심 개선 목표입니다.

상품 후보 탐지: 장면에서 상품으로 보이는 영역을 찾음

선택·윤곽 추출: 터치 위치의 상품을 잡고 배경을 제외

간단한 이름 생성: 청바지 · 가방 · 보라색 광선검

반복 상품 통합: 상품명·이미지·위치를 비교해 중복 제거

현재 AI는 범위가 정해진 로컬 인식 모델이다. 작은 물체, 가려진 상품, 지원이 약한 종류의 정확도는 남은 과제다. 밝은 광선검 후보 보완과 로컬 분류 검증을 PC에 추가했다. 윤곽 표시가 모든 상품에서 완성됐다고 주장하지 않는다.

## 7. 구매 연결: 현재는 Lens, 다음은 판매처 바로가기

이름만 검색해서 다른 상품이 나오는 문제를 이미지 중심으로 개선합니다.

현재 구현된 연결: 선택한 상품 사진 → Google Lens

비슷한 이미지·상품 결과 확인
검색 결과에서 판매 사이트로 이동
Lens와 판매 사이트에는 인터넷 필요

다음 개선 방향: 판매처로 바로가기 흐름 단축

사용자의 저장·업로드 작업 최소화
정보 확인부터 구매처 이동까지 간소화
동일·유사 상품을 명확하게 구분

사용자가 지적한 예시는 보라색 광선검이 LED 형광판으로 검색되는 문제다. 이미지 기반 검색으로 개선했으나 동일 상품 매칭과 구매 직행을 보장하지 않는다. 메모장의 판매사이트 직접 이동은 계획으로 표시했다.

## 8. 장면 수집과 영상 등장 시간

스캔을 켠 뒤 흐른 시간과 실제 영상의 재생 시간을 구분합니다.

장면 수집: 현재: 일정 간격의 화면 장면을 수집
전체 영상·소리를 녹화 파일로 저장하지 않음
모두 분석은 수집된 장면까지만 분석

계획: 연속 스캔으로 짧은 등장도 포착

시간과 영상 변경: 재생 시간·일시정지·이동 표시를 읽어 보정
확인되지 않는 시간은 “시청 추정” 표시
영상 변경 시 구분하고 이전 기록 유지

쇼츠·되감기·앱별 동작은 추가 검증

PC 화면 OCR과 Windows 미디어 세션 및 YouTube 화면 정보, Android 기기 내 OCR·타임라인 로직이 구현됐다. 실제 테스트 영상은 일시정지 상태에서 추정 0:00이 표시됐으므로 모든 영상의 정확한 시간 추적이 검증됐다고 표현하지 않는다. 현재 PC 수집 간격은 약 5초다.

## 9. PC 0.1.23: 실제 쇼츠 화면으로 개선 결과 확인

설치형·포터블 제공 · 사용자 PC에 0.1.23 설치 및 실제 분석 검증

확인된 개선: 영상 영역만 분석
다른 창에 가려진 장면 수집 중단
위젯을 영상 바깥쪽에 배치
간단한 상품명과 좁은 상품 사진
겹친 후보·반복 장면 통합

실제 유튜브 쇼츠 aAL9CokLGlI를 모니터에서 수집하고 설치된 앱에서 모두 분석했다. 결과는 광선검 1항목, 자동차 1항목이며 각각 3장면 기록이다. 브라우저 UI가 마우스·노트북으로 잘못 분석되는 것을 막았다. 이 사례는 전체 상품에 대한 성능 수치가 아니다. 화면 캡처 차단은 사용자 요청으로 해제했다.

## 10. Android 0.4.5: 기본 기능 구현, 실기기 안정화가 우선

모바일 중심의 제품 방향은 유지하되 PC와 동일한 완성도로 검증해야 합니다.

구현된 기반: 원형 시작 화면·화면 공유 권한
이동·축소·숨김이 가능한 위젯
상품 터치 선택·마킹·Lens 연결
수집 장면의 모두 분석·상품 목록
기기 내 AI·영상 시간 추적 로직

확인이 필요한 부분: 갤럭시 A15의 분석 중 종료 증상
실제 상품 윤곽 인식 정확도
선택 취소·실패 후 위젯 복원
메모리 부담·반응 속도
앱 전환과 Lens 복귀 흐름

0.4.3에서 버퍼 마지막 행·패딩 처리, 캡처 실패 복구, 시간 초과 시 위젯 복원, 해상도 상한 및 회전 복구를 보완했고 19개 단위 검사와 에뮬레이터 선택·취소·Lens 연결을 검증했다. 0.4.5가 현재 소스 버전이며 최신 PC 0.1.23 개선을 모바일에도 적용했다고 주장하지 않는다. 사용자가 메모장에 모바일 종료 버그를 남은 과제로 명시했다.

## 11. 현재 구현과 남은 작업을 한눈에

구현 여부와 검증 범위를 구분해 이후 개발 기준으로 사용합니다.

이미지 인식은 기기 안에서 실행되며 기존 API·서버 연동 코드는 일반 사용자 사용 흐름의 필수 조건이 아니다. 본 표는 목표와 현재 구현을 구분하는 실행 기준이다.

## 12. 다음 작업: 모바일 안정성부터 구매 편의까지

기획서의 우선순위를 유지하고, 각 단계의 확인 기준을 명확히 합니다.

새 기능을 늘리기 전에 모바일 종료 문제와 현재 화면 선택의 정확도를 우선 해결한다. 연속 스캔과 판매처 직접 이동은 기획 중인 후속 확장으로 별도 표기하며 일정·성능 목표를 임의로 약속하지 않는다.
