CleanTouch 영상 시간 연결

이 확장 기능은 영상의 실제 재생 시간을 CleanTouch에 알려줍니다.
시간을 읽을 수 없는 영상은 앱에서 ‘영상 시간 확인 안 됨’으로 표시합니다.
스캔을 시작한 뒤 지난 시간을 영상 시간으로 대신 표시하지 않습니다.

처음 한 번만 설치하면 됩니다.
1. CleanTouch 새 버전을 먼저 실행합니다.
2. Edge 주소창에 edge://extensions 를 입력합니다.
   Chrome은 chrome://extensions 를 입력합니다.
3. 개발자 모드를 켭니다.
4. ‘압축 해제된 확장 프로그램 로드’를 누릅니다.
5. 이 안내 파일과 manifest.json이 들어 있는 폴더를 선택합니다.
6. 열어 둔 YouTube·Instagram 페이지를 새로고침합니다.

영상이 있는 탭을 선택해 재생한 후 CleanTouch 스캔을 시작하세요.
여러 영상을 띄워 두면 가장 최근 선택한 브라우저의 영상과 연결됩니다.
다른 영상으로 바꾸거나 구간을 이동하면 시간과 영상 구분도 함께 갱신됩니다.
광고 중에는 본영상의 등장 시점으로 기록하지 않습니다.

이 기능은 영상 시간·제목·주소를 같은 PC의 CleanTouch에만 전달합니다.
외부 분석 서버, API 키, 별도 결제는 필요하지 않습니다.
개발자 모드 설치는 스토어 배포 전 테스트 방식입니다.
