# CleanTouch PC 0.1.38

일반 채팅과 화면 공유를 분리했습니다. AI 창을 열거나 첫 질문을 보내는 동작만으로 캡처·화면 전송이 시작되지 않습니다. 사진 없는 일반 질문도 가능합니다. 화면을 함께 보려면 사용자가 공유 버튼을 누르고 앱의 허용창에서 동의해야 합니다. Windows의 Electron 캡처는 운영체제 허용창이 항상 나타나는 구조가 아니므로 앱에서 별도 동의를 받습니다.

공유 허용 전의 네이티브 캡처 요청은 메인 프로세스에서 차단합니다. 허용은 앱의 주 프레임에만 적용되며, 15초 이내 한 번 사용할 수 있습니다. 마이크와 시스템 소리는 허용하지 않습니다. 공유 종료 시 새 프레임 전송을 중단하고 일반 채팅으로 돌아갑니다. AI 공유가 새로 시작한 캡처는 함께 종료하며, 사용자가 먼저 시작한 로컬 스캔은 유지합니다. 시작 도중 취소된 캡처가 늦게 도착해도 즉시 종료합니다.

처음 실행 안내와 다시 열 수 있는 사용 가이드를 추가했습니다. 일반 채팅, 공유 허용, 위젯 상품 선택, 구매 비교, 대화 기록의 5단계를 연습합니다. 연습용 화면은 앱 안에서 생성하며 실제 화면 캡처·AI 호출·외부 사이트 이동·구매를 실행하지 않습니다. 기존 대화 저장과 복원 기능은 유지합니다.

## 검증

- PC 단위 테스트 81개 통과. 캡처 허용의 주체·만료·일회성·오디오 차단, 텍스트 연결의 이미지 미전송, 공유 전환 후 프레임 중단, 늦은 캡처 취소를 포함합니다.
- 최종 app.asar를 사용한 Electron 대화 통합 검사 통과. 사진 분석·Lens·대화 복원·취소·늦은 응답 차단과 일반 채팅/공유 허용/종료를 검사했습니다.
- 사용 가이드의 5단계 연습과 동의 거절·Escape·허용 경로를 Electron에서 검사했습니다.
- 실제 Gemini 연결에서 이미지 없이 일반 질문의 답변을 받았습니다. 허용 전 캡처 차단, 동의 거절, 허용 후 전송, 종료 후 이미지 미전송 및 일반 질문 응답을 확인했습니다. 텍스트와 화면 전환은 같은 연결을 재사용합니다. 검증 파일은 `artifacts/verification/release-0.1.38-*`에 있습니다.
- 이후 캡처 소유권·닫기와 레이아웃을 보강했습니다. 마지막 실제 공유 재검사에서는 열린 브라우저가 영상 페이지가 아니어서 영상 감지가 실패했으며, 관련 없는 화면은 전송하지 않고 캡처를 해제했습니다. 최종 취소·소유권 처리는 모의 스트림 통합 검사로 검증했습니다.
- Windows 설치 완료(종료 코드 0), 설치 버전 0.1.38 및 핵심 파일 14개의 설치본·최종 패키지·소스 일치를 확인했습니다. 실제 프로필에서 처음 실행 가이드, 일반 채팅의 공유 꺼짐 표시, 기존 대화 목록을 직접 확인했습니다. PC 패키지 326개 파일과 기존 APK 545개 파일, Windows 실행 파일 두 종류에서 운영자 키 미포함을 확인했습니다. Setup/Portable은 Downloads와 artifacts/downloads에 저장했으며 SHA-256과 업데이트용 SHA-512를 검증했습니다. 새 공개 릴리스는 게시하지 않았습니다.

## 범위

이번 변경은 PC에 적용했습니다. Android APK는 기존 0.4.8이며 새 사용 가이드를 적용한 모바일 빌드는 만들지 않았습니다. 서버 변경과 새 배포는 필요하지 않습니다. 기존 상품 인식의 추정 가능성, 운영 계정의 Google 검색 사용 한도 및 판매처 검증 제한은 0.1.37 품질 기록에 기재한 그대로입니다. 모든 사이트·PC·휴대폰의 실사용 검증을 완료했다는 의미는 아닙니다.
