# CleanTouch PC 0.1.40

0.1.39에서 기존 대화의 제목을 복원한 뒤 생성 여부가 없다는 이유로 공통 기본 제목을 저장했습니다. 기존 대화는 새 질문을 하지 않으면 AI 제목을 받을 기회도 없었습니다. 이제 공통 제목 대신 대화의 단어·상품 검색 내용을 이용한 임시 주제를 표시하고, 제목 없는 저장 대화는 텍스트만으로 AI가 요약합니다.

제목 정리는 최대 6개 대화를 하나의 요청으로 묶어 처리합니다. 화면·사진·소리는 전송하지 않으며, 최근 12개 발화의 제한된 텍스트와 상품 검색어만 제공합니다. 정상 요약은 저장한 뒤 다시 요청하지 않습니다. 실패한 같은 내용은 30분 동안 재시도하지 않습니다. 새 질문에서 정상 제목을 받은 대화는 추가 요청을 하지 않습니다.

제목 저장 직전 대화의 내용 지문을 비교하므로, 처리 중 바뀌거나 삭제된 대화 또는 이미 정상 제목을 얻은 대화를 뒤늦게 덮어쓰지 않습니다. 기존 제목 생성 상태가 없는 화면이 저장을 시도해도 완료된 AI 제목을 보존합니다. 제목 변경은 사이드바와 현재 대화 제목에 반영하며, 대화 메시지·선택 사진·기존 시간은 변경하지 않습니다.

## 검증

- PC 단위 테스트 88개 통과. 서로 다른 대화의 임시 제목, AI 제목 보존, 늦은 제목/삭제 충돌 차단, 배치의 텍스트 전송만 허용, 일반 제목·중복 인덱스 거절, 실패 재시도 제한을 포함합니다.
- 소스 및 최종 app.asar Electron 통합 검사 통과. 사진 첨부의 대화 유지·목록 유지·대화 저장과 복원·기존 공유 동의 검사를 유지합니다.
- 실제 Gemini 배치 검사에서 3개 대화가 서로 다른 제목으로 생성됐습니다. 실제 앱의 격리된 QA 프로필에서는 기존 기본 제목을 자동 정리하고 사이드바·현재 제목 갱신 및 저장 후 보존을 확인했습니다. 이 검사에서 캡처와 화면 공유는 꺼져 있었습니다. 자료는 `artifacts/verification/release-0.1.40-title-batch.json`, `release-0.1.40-title-repair.json` 및 PNG입니다. QA 데이터는 작성한 예시이며 사용자 프로필을 덮어쓰지 않았습니다.
- 서버와 Android APK는 변경하지 않았습니다. 제목은 AI 추정이며 요약 실패 시 대화에서 뽑은 단어를 임시 제목으로 사용합니다. 사용량 제한이 있는 경우 제목 생성도 지연될 수 있습니다.
- 실제 설치 종료 코드 0, 버전 0.1.40 및 핵심 파일 16개의 설치본/패키지/소스 일치를 확인했습니다. 사용자 프로필의 기존 3개 대화가 모두 생성된 서로 다른 제목으로 정리됐습니다. 교체 전후 메시지·AI 문맥·첨부 사진의 해시와 기존 시간을 비교해 모두 보존됐음을 확인했습니다. 검증 결과는 `release-0.1.40-installed-title-repair.json`이며 대화 본문을 출력하지 않습니다. 패키지 328개 파일/기존 APK 545개 파일 및 설치형/포터블에서 운영자 키 제외를 확인했습니다. 두 실행 파일과 업데이트용 해시/파일은 준비했고 공개 릴리스는 게시하지 않았습니다.
