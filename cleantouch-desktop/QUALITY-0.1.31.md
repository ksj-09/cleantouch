# CleanTouch 0.1.31 — 화면 작업과 품질 개선

## 변경

- 위젯에 시작 버튼, 접기/펼치기, 장면 확인, 잘못된 결과 제외를 추가했다. 기본 메뉴를 제거하고 모니터에 맞춰 창을 배치한다. Windows 최대화 상태를 해제한 뒤 배치해 접기·선택 화면 전환이 실제로 적용되도록 했다.
- 대화 창에서도 상단 장면 미리보기를 유지한다. 사진을 먼저 올리지 않아도 질문을 작성하고 화면 공유를 시작할 수 있다.
- 상품 사진을 잘라 채우지 않고 전체가 보이도록 표시한다. 결과·하단 버튼 겹침을 수정했다.
- 다른 창이나 위젯이 영상을 가리면 수집을 보류한다. Windows 가림 검사 보조 프로세스의 DPI 배율을 맞춘다. 스캔 정지 시 미리보기도 고정한다. 실패 안내가 완료 문구에 덮이지 않도록 수정했다.
- 전체 분석은 시작 시점의 장면 수를 고정한다. 연결 제한은 자동으로 재시도하며, 반복 실패하면 장면과 결과를 유지하고 중단한다. 대기 중에도 즉시 취소할 수 있다.
- 이름이 조금 달라도 충분히 비슷한 사진과 위치에 해당하면 중복을 묶는다. 서로 다른 위치의 상품과 다른 종류의 옷은 합치지 않는다.
- 너무 작거나 흐린 자동 후보는 결과에서 제외한다. 원본 장면의 직접 선택은 남아 있다.
- 윤곽이 사람이나 배경까지 포함하면 ‘잘못 잡힌 부분 빼기’로 AI에 제외점을 지정할 수 있다. 최초 선택 모델은 스캔 시작 시 미리 준비한다.

## 실제 확인

열린 YouTube 광선검 쇼츠의 영상 영역을 수집하고 전체 분석의 자동 정지와 상품 결과를 확인했다. 저장한 실제 파란 광선검 장면에서 마우스 선택을 실행했다. 최초 윤곽은 사람까지 포함했고, 사람의 상체를 제외점으로 누른 후 얼굴·상체가 빠지고 선택한 칼날이 유지되는 것을 확인했다. 기록은 `artifacts/verification/mask-correction.json`과 PNG에 남겼다.

Node 회귀 테스트 49개와 Electron 통합 시나리오를 실행한다. 새 통합 검증은 위젯 접기/복원, 결과·버튼 겹침 방지, 채팅 중 미리보기 유지, 상품 제외, 연결 대기 자동 재시도 및 대기 중 취소를 확인한다.

49개 테스트와 `continuous-analysis`, `place-chat`, `scene-grounding`, `review-workspace` 통합 실행이 모두 통과했다. 실제 Windows 창을 최대화한 후 접어 326×120 물리 픽셀 창으로 복귀한 것도 확인했다. 보정한 파란 광선검 사진은 공개 AI에서 ‘파란색 광선검’으로 식별됐으며 동일 이름의 쇼핑 검색어가 생성됐다. 최종 `dist-0.1.31-ready` 설치형·휴대형을 만들고, 번들 주요 소스 일치 및 두 EXE에 운영자 Gemini 키가 없음을 검사했다.

## 남은 제한

이 빌드는 고객 검증용이며 모든 버그가 해결된 상용 출시 판정은 아니다. 최초 윤곽이 물건 대신 사람을 잡는 경우가 있어 보정이 필요할 수 있다. 흐린 영상, 빠른 상태 변화, 아주 작은 상품은 놓칠 수 있다. 전체 분석 속도는 운영자 AI 호출 한도와 장면 수의 영향을 받는다. AI 질문은 질문 시 최근 장면들을 전송하며 무제한 동영상 스트리밍은 아니다. 설치 파일은 서명되지 않았다. 이 변경은 PC에 적용하며 Android의 실제 Galaxy A15 검증은 별도 진행이 필요하다.
