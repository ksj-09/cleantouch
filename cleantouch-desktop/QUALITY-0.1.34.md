# PC 0.1.34 — 친근한 쇼핑 도우미 디자인

CleanTouch PC의 기본 화면을 따뜻한 아이보리와 보라색 중심으로 바꾸고, 살구빛 보조 색상으로 화면을 부드럽게 했다. 기존의 짙은 테마는 해 아이콘 버튼으로 전환할 수 있고 선택은 기억된다.

- 상품을 연상시키는 쇼핑백·반짝임 브랜드 마크와 Windows 앱 아이콘을 새로 그렸다.
- AI, 이미지 검색, 제외 동작에 같은 선 굵기의 벡터 아이콘을 적용했다.
- 위젯 처음 사용자를 위한 세 단계 안내를 추가했다. 캡처를 시작하거나 위젯을 접거나 대화를 열면 안내는 숨긴다.
- PC·위젯·상품 카드·AI 대화에 모서리, 색, 그림자 규칙을 적용했다.

이번 변경은 Windows PC에만 적용했다. PC 미리보기에서 대시보드와 위젯을 직접 확인했다. 모바일 APK의 화면은 바뀌지 않았다.
