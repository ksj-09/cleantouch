# CleanTouch PC 0.1.36 검증 기록

## 사용 흐름과 안정화

- 화면 수집 → 위젯에서 상품 선택 또는 전체 분석 → AI 설명·쇼핑 검색·Lens로 이어지는 동작을 유지하고 버튼 배치와 대비를 정리했습니다. 밝은/어두운 테마, 접은 위젯, 작은 높이의 대화창을 지원합니다.
- 전체 분석 시작 시 수집을 일시정지합니다. 취소하면 완료 결과와 남은 장면을 유지하고, 분석 또는 수집을 각각 재개할 수 있습니다. 수집만 멈춘 상태를 분석 완료로 표시하지 않습니다.
- 동일한 연속 JPEG 장면을 한 번만 보관해 멈춘 영상의 반복 분석을 줄였습니다. 선택을 위한 현재 사진은 계속 새로 가져옵니다.
- 이전 세션의 캡처·마킹·AI 응답이 새 세션에 들어가지 않도록 취소와 세대 검사를 보강했습니다. 영상 위치 조회 실패, 가림, 잘린 영상은 전체 바탕 화면으로 대체하지 않습니다.
- 사용하지 않는 API 키·LAN 서버·연결 모드 IPC를 제거했습니다. 일반 사용자에게 운영자 키를 배포하지 않습니다.
- Live 재연결 후 입력 상태를 복원하고, 빈 답변·중단·시간 초과를 재시도 가능한 오류로 처리합니다. 무한 재연결 대신 간격을 늘려 최대 세 번 시도하고, 긴 사용량 대기에서는 종료합니다.
- 초기 프레임과 질문을 서로 다른 Live 입력 채널로 보내던 방식을 정리했습니다. 프레임을 순서가 보장되는 이미지 문맥으로 보내고 그 뒤 질문을 전달합니다. 답변 중 새 이미지가 진행 중인 답변을 끊지 않도록 일시적으로 AI 프레임 전송을 기다립니다. 기기의 영상 재생과 화면 수집은 독립적으로 동작합니다.
- 창 크기를 작업 영역에 맞추고 중복 실행을 막았습니다. 주 창을 종료하면 캡처 보조 프로세스와 요청을 정리합니다. 영상 위치가 확인되면 해당 모니터를 우선 캡처합니다.

## 검증

- 데스크톱 단위 테스트 69개 통과: 캡처 실패·취소·중복 저장, 마스크/객체 후보, 이름/색상/중복, 시간 추정, Live 연결·재연결·빈 응답·시간 초과, 통신 오류, 업데이트 동의 흐름.
- Electron 통합 검사: 사진 선택/처리·후속 질문·실패 후 재시도·독립적인 AI/Lens 실행·마킹 취소·오래된 결과 차단, 위젯/대화 배치, 전체 분석 대기 취소.
- 실제 로컬 모델: 가방 마스크에 가방 몸체가 포함되고 얼굴은 제외됨. `artifacts/verification/bag-whole-mask.png`.
- 공개 AI 서비스: 가방 사진을 `검은색 숄더백`으로 인식했으며 화면 이름과 쇼핑 검색어가 일치함. 손상된 사진과 잘못된 JSON 요청은 400으로 거부함. 서버 빌드 및 테스트 58개 통과.
- 실제 Gemini Live: 고정된 빨간 광선검 장면에 대한 순서 보장 이미지 입력 시험에서 종류와 색상이 일치함. `artifacts/verification/live-ordered-probe.json`. 세션 재연결은 실제 API를 사용하되 예정된 8분 타이머를 시험 중 단축하여 검사합니다.
- Android 기존 0.4.8 소스의 단위 테스트와 lint 통과. 이번 PC 변경과 동일한 기능이 APK에 반영됐다는 검증은 아닙니다.
- 최종 패키지 `dist-0.1.36-verified`로 실제 영상 캡처·대화 배치·첫/후속 응답·실제 API 세션 재연결·공유 종료를 확인했습니다. 질문 이미지와 실제 답이 광선검 장면/색상에 부합했습니다. 결과는 `artifacts/verification/release-0.1.36-smoke.json`과 같은 폴더의 질문 이미지입니다.
- NSIS 설치 종료 코드 0, `C:/Users/first2000/AppData/Local/Programs/CleanTouch` 제품 버전 0.1.36.0 확인. 설치된 주요 파일이 검증한 app.asar와 일치하며 사용자 프로필에서 홈 화면을 확인했습니다.
- PC 설치형/휴대형과 기존 APK에서 운영자 키가 제외됨을 검사했습니다. 설치 파일은 `C:/Users/first2000/Downloads/CleanTouch-Setup-0.1.36.exe`; 공유용 exe와 SHA256은 `artifacts/downloads`에 있습니다.
- 새 다운로드 서버 실행은 자동 승인 검토에서 `blocked by policy`로 거절되어 새 HTTP 주소를 제공하지 않았습니다. 기존 8100 서버는 이전 페이지를 서비스할 수 있습니다. 이번 전달물은 설치된 PC 앱과 로컬 설치 파일입니다.

## 남은 배포·제품 제한

- AI는 사진에 근거한 추정입니다. 모든 상품, 브랜드, 판매처, 가격이나 동일 상품 구매를 보장하지 않습니다. 구매 연결은 쇼핑 검색 또는 Lens이며 결제는 판매 사이트에서 사용자가 진행합니다.
- AI 공유는 초당 최대 1장으로 제한하며 빠른 움직임을 전부 읽지는 못합니다. 소리·GPS·전체 영상 파일을 보내지 않습니다. 영상을 찾지 못하면 공유를 중단합니다. 현재 실제 확인한 자동 감지는 Edge YouTube Shorts이며 Instagram과 모든 플레이어 지원을 검증하지 않았습니다.
- 모바일에는 이 PC Live 화면 대화/스타일 변경을 아직 포팅하지 않았습니다. 갤럭시 A15 실기기에서 최신 경로를 다시 검사해야 모바일 완료로 볼 수 있습니다.
- Windows 파일은 코드 서명이 없습니다. 자동 업데이트 메타데이터는 만들지만 이번 작업에서 GitHub 정식 공개 릴리스를 발행하지 않습니다. 기존 Android 중심 GitHub 릴리스에 데스크톱 업데이트 정보가 없는 경우 확인은 조용히 실패하고 자동 설치하지 않습니다.
- 공개 Netlify 요청 제한은 인스턴스 메모리에 있으므로 전체 서비스의 영구적인 비용 상한이 아닙니다. Live 기본 30건/일, 사진 분석 기본 500건/일은 시험용 제한이며 실제 공개 규모에 맞춰 운영자가 공급자 사용량/과금을 관리해야 합니다.

참고: [Google Live API 기능](https://ai.google.dev/gemini-api/docs/live-api/capabilities), [공식 SDK의 입력 순서와 채널 혼합 안내](https://github.com/googleapis/python-genai/blob/main/google/genai/live.py).
