# CleanTouch Windows 앱

Android APK는 Windows에서 실행되지 않습니다. 이 폴더는 Windows 10/11용 CleanTouch 앱입니다. 유튜브가 재생되는 브라우저 창 또는 전체 화면을 선택한 뒤 시청하고, 중지하면 추출한 장면을 기존 CleanTouch 검색 서버에 보내 상품 검색 링크를 보여줍니다. 음성이나 동영상 파일은 저장하지 않습니다.

## 설치와 사용

- `dist/CleanTouch Setup 0.1.3.exe`: 설치형
- `dist/CleanTouch 0.1.3.exe`: 설치 없이 실행하는 휴대형

현재 개발 PC와 같은 네트워크에서는 `http://192.168.100.103:8100/`에서도 Android APK와 두 Windows 파일을 내려받을 수 있습니다. 다른 네트워크에서 다운로드하려면 이 파일을 공개 배포 사이트에 올려야 합니다.

새 설치의 기본값은 **기본 연결 · 키 불필요**입니다. 사용자는 키를 발급받지 않고 운영자의 Gemini 서버를 사용합니다. 현재 기본 서버 주소는 개발 PC의 로컬 네트워크 주소이므로 일반 사용자에게 배포하기 전 HTTPS 공개 서버로 옮기고 설치 파일의 기본 주소를 바꿔야 합니다. 서버의 모든 사용량은 운영자 계정에 모입니다. 서버에 Cloud Vision 인증까지 설정하면 상품 영역의 이미지가 일치하는 웹페이지가 문자 검색보다 먼저 나타납니다. 이 설정이 없다면 문자 검색 링크만 나타납니다. 정확한 판매 상품이 보장되는 것은 아닙니다.

**내 Gemini 키 사용**은 선택 사항입니다. 이 방식은 서버 없이 다른 네트워크에서도 작동하며, 키는 Windows 계정으로 암호화해 이 PC에 저장합니다. 이미지 분석 요청은 PC에서 Gemini로 직접 전송됩니다. 창 목록에서 유튜브 창을 고르고 **화면 살펴보기 시작**을 누른 뒤 시청하고, **중지하고 분석**을 누르세요.

이미지 일치 검색을 서버에서 사용할 수 없을 때도 결과 카드의 **이 사진으로 Google Lens에서 찾기**를 누를 수 있습니다. 앱이 해당 상품의 잘린 사진을 다운로드 폴더에 저장하고 Google Lens를 엽니다. 사용자가 Lens 이미지 업로드에 저장된 사진을 넣으면 유사 이미지를 볼 수 있습니다. 사진은 사용자가 지울 때까지 다운로드 폴더에 남습니다.

새 녹화는 5초마다 장면을 추출합니다. 장면이 24개에 도달하면 간격을 두 배로 늘려 영상 전체에서 최대 24장을 유지합니다. 이미 성공한 장면과 상품은 같은 실행 중에 재시도할 때 유지됩니다. 앱을 닫으면 아직 분석하지 않은 장면은 사라집니다.

**검색 서버 연결**도 선택할 수 있습니다. 초기 서버 주소 `http://192.168.100.103:8790`은 현재 개발 PC의 로컬 네트워크 주소이며 같은 네트워크의 PC에서만 연결됩니다. 다른 장소에서 서버 모드를 쓰려면 HTTPS로 접속 가능한 공개 검색 서버가 필요합니다. 본인의 Gemini 키나 서버의 키는 설치 파일에 포함되지 않습니다. 서버 모드의 모든 사용량은 해당 서버 계정에 청구·집계됩니다.

실행 중인 검색 서버가 Gemini 설정을 읽었는지는 앱의 연결 확인에 `Gemini 서버 연결됨`이 표시되는지 확인하세요. 이전 서버 프로세스이거나 공급자가 다르면 시작 버튼이 비활성화되며 서버 업데이트와 재시작이 필요합니다. 실제 Gemini 이미지 분석은 제공자 503 응답 때문에 아직 성공 검증되지 않았습니다.

## 개발자 빌드

```powershell
cd cleantouch-desktop
npm.cmd install
npm.cmd run start
npm.cmd run dist:win
```

PC 앱은 선택한 방식에 따라 화면 이미지를 Electron의 메인 프로세스에서 Gemini 또는 검색 서버로 전송합니다. 화면을 표시하는 프로세스에는 파일 시스템과 Node.js 권한을 주지 않고, 키 입력란은 저장 즉시 비웁니다. 설치 파일은 코드 서명 인증서 없이 빌드되므로 Windows의 게시자 확인 경고가 표시될 수 있습니다.

패키지 검증은 `node test/smoke.mjs`로 합니다. `--remote-debugging-port=9223`으로 실행한 개발용 Windows 앱을 대상으로 화면 캡처 → 테스트 서버 업로드 → 상품 응답을 확인합니다. 이 검증에는 실제 Gemini 키를 사용하지 않습니다.
