# CleanTouch 0.1.29–0.1.30 안정화 검증

## 이번 변경

0.1.30은 영상이 다른 창에 가려졌을 때 현재 화면 분석으로 이전 캡처 장면을 여는 동작도 막는다. 가려진 영상임을 안내하고 다시 선택하게 한다.

- 모두 분석은 스캔을 먼저 일시정지하고 고정된 장면 목록을 처리한다. 분석 중단은 요청을 취소하며 장면과 확인된 상품을 유지한다. 재개한 작업을 이전 응답이 덮어쓰지 않는다.
- AI 장애·사용량 제한으로 확인하지 못한 장면을 완료 처리하거나 실패 결과를 캐시하지 않는다. 이어서 분석할 수 있다.
- AI가 검증한 상품을 제한된 로컬 분류 목록의 ‘미확인’ 결과 때문에 버리지 않는다. 명확히 다른 상품 종류가 확인될 때만 충돌로 거른다. AI 결과가 있더라도 다른 상품 영역을 탐색한다.
- 로컬 모델이 실패하더라도 AI가 확인한 상품을 표시한다. 같은 이름의 별개 상품이 서로 덮어쓰지 않는다.
- 여러 장면의 상태·형태 근거를 확인하고, 흐릿한 배경 조각은 제외한다. 상품 대표 사진은 선명도와 전체 형태를 기준으로 선택한다.
- 업로드 사진은 바로 질문할 수 있다. 사진 선택 시 화면 공유를 종료하고, 사진과 실시간 장면이 섞이지 않도록 대화 출처를 분리한다. 실패한 화면 질문을 재시도할 수 있다.
- 복잡한 사진도 전송 용량을 지키도록 JPEG 품질과 크기를 단계적으로 조절한다. 일시정지한 화면과 과거 장면에서 상품을 다시 선택할 수 있다.
- 표시한 짧은 상품명과 쇼핑 검색어를 일치시킨다. Lens와 AI 쇼핑 분석은 각각 선택한다.

## 검증 범위와 출시 조건

API 자동 테스트, 데스크톱 단위 테스트, Electron에서 분석 중단·재개·업로드·채팅·중복·장면 근거·이미지 크기 회귀 테스트를 실행한다. 설치 파일에 운영자 키가 포함되지 않는지 별도로 검사한다.

자동 테스트는 다양한 실제 고객 영상의 정확도를 보장하지 않는다. 조명, 가림, 빠른 움직임, 작은 상품의 오인식·누락은 실제 데이터로 계속 평가해야 한다. 상품 후보는 동일 모델의 확정 결과가 아니며 쇼핑 링크도 실제 재고나 최저가를 보장하지 않는다.

현재 화면 함께 보기는 기기에서 최근 장면을 수집하고 질문할 때 선택한 여러 장면을 보내는 방식이다. Gemini가 모든 프레임을 상시 시청하는 영상 통화 방식은 아니다. 공개 AI 서비스의 처리량과 운영 비용 제한이 있으며, 제한을 숨기거나 무제한으로 설명하지 않는다.

이번 Windows 안정화 빌드는 고객 검증용이다. 일반 배포 전 Windows 코드 서명, 실제 사용 영상 평가, 여러 PC 환경 점검, 운영 서비스의 부하·비용 검증이 필요하다. Android에 이번 Windows 변경이 모두 반영됐다고 주장하지 않는다. 모바일은 Galaxy A15 실기기에서 캡처·위젯·마킹·복귀 흐름을 별도로 검증한다.

## 이번 실행 결과

- API 56개, PC 47개, Android 단위 테스트 22개 통과.
- Electron 앱에서 분석 자동 일시정지·유한 큐 완료·중단·새 작업과 이전 응답 격리·사진 업로드 직후 질문·선택 이미지의 쇼핑 검색·실패 재시도·별개 동일 이름 상품 보존·큰 이미지 전송 예산을 검증.
- 새 Windows 패키지에서 공개 AI를 통한 검은색 숄더백 분석, 표시 이름과 검색어 일치, 후속 질문, 위치를 확인할 수 없는 장면에 대한 보수적 응답을 확인.
- 공개 AI 장면 검증에서 꺼진 흰색 칼날 후보가 제외됐다. 다만 반복 실행에서 실제 색상별 상품의 반환 개수가 달라졌다. 따라서 이 사례의 오인식 수정과 모든 상품의 누락 없는 인식을 동일한 성과로 설명하지 않는다.
- 새 PC 패키지와 기존 APK의 운영자 키 미포함을 검사했다. Android 단위 테스트 통과는 실제 Galaxy A15 검증을 대체하지 않는다.
- Android 16 에뮬레이터의 기본 테스트 11개 중 7개 통과, 외부 서비스·화면 공유 통합 테스트 4개는 별도 실행 옵션이 필요해 건너뛰었다. 테스트용 APK는 `-PCLEANTOUCH_TESTING -PCLEANTOUCH_EMULATOR` 옵션으로 검증하고, 이후 일반 ARM 빌드 설정으로 복구했다. 에뮬레이터 결과는 일반 배포 APK나 Galaxy A15의 검증과 동일하지 않다.
