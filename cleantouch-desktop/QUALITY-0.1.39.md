# CleanTouch PC 0.1.39

사진 업로드와 파일 목록 선택 시 현재 대화의 메시지·기록 ID를 유지합니다. 업로드한 사진은 해당 대화에 첨부 메시지로 표시하며, 질문을 보내기 전에는 AI 요청을 보내지 않습니다. 사진 모드로 전환할 때 화면 공유 연결은 종료합니다. 취소되거나 실패한 파일 선택은 기존 대화를 지우지 않습니다. 새 대화는 이전 사진을 자동으로 가져오지 않습니다.

대화 목록에서 대화를 선택해도 사이드바를 닫지 않습니다. 새 대화 버튼 역시 열린 목록을 유지하며, 닫기 버튼으로만 목록을 접습니다.

제목은 첫 질문을 그대로 복사하지 않고 AI 답변의 주제를 짧게 요약합니다. 제목을 위해 별도 AI 호출을 만들지 않고 기존 질문의 응답에 제목 표식을 요청합니다. 스트리밍 중에도 표식을 본문에서 숨기며, 생성된 제목과 표시한 답변만 저장합니다. 사진 응답의 JSON 형식은 유지합니다. AI가 제목을 주지 않으면 인사·사진·상품 비교 등 내용에 맞는 간단한 제목을 사용합니다. 기존 대화는 다음 선택/저장 때 정리하며, 생성된 제목은 앱 재시작과 대화 복원 뒤에도 유지합니다.

## 검증

- 단위 테스트 84개 통과. 제목의 분할 스트리밍·길이 제한·잘못된 표식·본문 분리와 기존 캡처·분석·대화 저장 검사를 포함합니다.
- 소스 및 최종 app.asar Electron 통합 검사 통과. 인사 이후 사진 두 장을 순차 첨부해 ID·기록 수·이전 메시지가 유지되는지 확인했습니다. 파일 업로드만으로 AI 요청이 실행되지 않고, 선택한 사진으로 후속 질문이 전송되는 것을 확인했습니다. 사이드바 유지, 제목 표식 미노출, 대화 복원·Lens·삭제 및 기존 공유 동의/취소 검사를 포함합니다.
- 실제 Gemini 텍스트 연결에서 “영상 보면서 마음에 든 가방을 찾아보고 싶어. 어떤 특징을 비교해야 할까?”에 답변을 받았고, 제목 “영상 속 가방 비교 특징”이 생성됐습니다. 화면 캡처와 공유는 꺼져 있었습니다. 결과는 `artifacts/verification/release-0.1.39-real-title.json`과 PNG에 있습니다.
- 기존 서버와 Android APK는 변경하지 않았습니다. 이번 변경에 새로운 API 키나 서버 설정은 필요하지 않습니다. 기존 인식 정확도·검색 사용 한도·다양한 기기 검증의 제한은 0.1.37/0.1.38 기록을 참고합니다.
- Windows 설치 종료 코드 0, 설치 버전 0.1.39 및 핵심 파일 15개의 설치본/asar/소스 일치를 확인했습니다. 실제 프로필에서 이전 대화를 선택해 메시지가 복원되고 사이드바가 열린 상태로 유지되는 것을 화면에서 확인했습니다. 기존 기록 파일은 유지했습니다. 패키지 327개 파일과 기존 APK 545개 파일 및 Windows 설치형/포터블에서 운영자 키 제외를 확인했습니다. 두 PC 실행 파일은 Downloads와 artifacts/downloads에 저장했고 릴리스 해시와 업데이트 파일을 준비했습니다. 새 공개 릴리스는 게시하지 않았습니다.
