# CleanTouch — 화면 속 상품 모아보기

## 사용 경험

앱 안의 큰 원형 버튼으로 ON/OFF 합니다. 다른 앱 위에 떠다니는 UI는 없습니다.
ON 동안 무음으로 화면을 녹화하고, 앱에서 OFF 하면 전체 녹화 구간의 상품 분석을 자동 시작합니다.
인식한 상품들을 개별 사진·등장 시점·쇼핑 검색 링크와 함께 보여줍니다.

## 현재 구현

- Android 네이티브: MediaProjection + MediaRecorder. 시간 제한 없이 사용자 종료까지 녹화(시스템 종료·저장 용량 한도 예외).
- 종료 후 약 2초 간격 및 마지막 장면 추출. 여러 객체 인식, 검색 경로 중복 제거, 상품별 사진 저장.
- 분석 진행률, 상품명 필터, 오류 표시, 실패 시 이어서 분석, 재실행 후 최신 결과 복원.
- Android 알림에서 종료/분석 중지/결과 열기. 앱·알림에 전용 별/스캔 아이콘.
- 웹: 같은 조작 흐름을 시연하는 예시 결과 기반 시제품.

## 표현 원칙

상품을 전부 빠짐없이 인식한다고 보장하지 않습니다. 가려짐, 작은 상품, 짧은 등장, 보안 화면, 모델 오류 등으로 누락될 수 있습니다.
현재 검색 링크는 AI가 읽은 특징을 쇼핑 검색으로 연결합니다. 동일 상품이나 가격을 확정하지 않습니다.
녹화는 앱 전용 저장소에 두고, 분석 완료 후 원본만 자동 삭제합니다. 실패한 녹화는 재시도를 위해 보존합니다.

## 다음 제품 과제

실기기 장시간 녹화·회전·잠금 검증, 장면 변화 기반 샘플링, 객체별 추적 및 동일 제품 통합, 실제 제휴 상품 카탈로그와 가격 연동.
